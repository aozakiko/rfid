# 统计实验规格 v1

本文件冻结本次统计算法和实验实现的可复现口径；统一接口以可复现测试为准。

## 输入与输出契约

共同接口位于 `code_add/stat_protocols/contracts.py`，均为 dataclass 并有回归测试。TaskSpec 包含任务列表、公开整数值域、分布、规模、seed、缺失/噪声/极端值概率、误差约束与数据拆分。默认任务为 mean、variance、cardinality、top_k；正式域为1..1000。

RunResult 包含真值、估计值、reader_bits、tag_bits、slots、frames、rounds、CPU、seed、failure_reason；metadata 带 distribution、num_tags、observed_num_tags、dataset_hash、split、扰动参数、collection_id、bundle_cost 和测量轨迹。EvaluationReport 分别提供执行状态、相对/绝对误差或 precision/recall/F1/Jaccard；运行成功不代表达到精度要求。

ProtocolCandidate 是与演化模块协作的载体；`genotype.compile_candidate(record)` 只编译匿名直方图的合法参数，避免任意 Python 执行。统一数据 Schema 以测试和文档为准。

## 统计与通信定义

| 项 | 定义 |
| --- | --- |
| mean / variance | 在场属性值的均值 / 总体方差 |
| cardinality | 在场标签数量，不是 distinct 属性数 |
| Top-k | 频次降序、属性值升序打破并列，取恰好 k 项；F1评价完整集合 |
| reader bits | 单帧8位opcode + 64位seed + 32位下界 + 32位上界 + 24位帧布局，共160位 |
| tag bits | 每个标签每帧发射1位匿名贡献，包含碰撞；不是成功解码吞吐量 |
| slots | 所有公开值桶的预留槽数，含空闲槽；单帧为值域宽度 × 每值槽数 |
| frames / rounds | 每次独立测量的逻辑超帧 / 交互轮数；尚未映射到硬件最大帧长 |
| 模拟成本 | CostModel 的透明线性组合；无硬件依据，不当作链路时延 |

固定槽数 m 的桶，n 个独立标签均匀哈希时空槽期望为 `E[Z] = m(1-1/m)^n`。以观察到的Z反演 n：`n_hat = log(Z/m) / log(1-1/m)`。饱和Z=0不可识别，以Z=1作截断并明确记录 saturated_bins；不能说截断是无偏估计。

共享直方图 `c[v]` 的均值为 `sum(v*c[v])/sum(c[v])`，方差为 `sum((v-mean)^2*c[v])/sum(c[v])`，基数为`sum(c[v])`，Top-k按c[v]排序。这是复用同一统计信息的近似协议，不以真值替代估计。

自适应使用边界第k和k+1候选的估计频差与delta-method方差之比，阈值0.5/1/2；最多4帧。全帧复核有意保留为明确可比原型，不声称已经具备候选定向复核或概率保证。

## 公平对比与验收

同一分布、规模、seed、扰动下，所有协议接收同一个数据集合。报告数据hash用于核对；确定性SplitMix64替代进程随机hash。独立hash轮次用于匿名测量，不改动数据seed。

H1单独比较三任务串联和共享，费用从bundle_cost取一次；默认四任务主实验不能冒充三任务H1。门槛为通信节省≥15%，均值/方差/基数相对误差95%CI上界≤5%/10%/5%。该口径比仅比较误差均值更保守。

H2以相同seed配对，报告自适应相对固定4轮的F1损失均值、95%CI和通信节省；门槛为损失CI上界≤1个百分点且节省≥20%。固定2/3轮、无复核和不同阈值也全部保留。它检验文档H2的“相近准确率下节省通信”分支；不拿未测的“同开销提高2个百分点”分支填充结论。

20个独立seed支撑每一单场景的Student-t 95%CI。P95取nearest-rank，worst取最大值；跨场景总体均值仅为描述性汇总，不作为独立样本推断。盲测seed100–119，不参与阈值调整。

四类必须基线：Polling、无碰撞全识别乐观下界、与共享使用相同测量原语的单任务专用及串联、真实LLM单次受限基因生成。随机参数控制组另列。没有真实调用记录时保留待实测；不声称完成真实LLM科研对照，也不把此单候选试验扩展成H3演化质量结论。

原始 JSON/CSV、机制来源SHA-256、失败行、饱和与负结果随成果保留。无硬件和验证器结果时不使用“已证明信息隔离”“真实时延提升”等表述。
