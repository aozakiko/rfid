## 功能迁移

1. **研究总览**：真实场景资产计数、任务概览、研究流程入口。
2. **场景与代码**：场景创建、基线复制、搜索和分页、文件编辑、Ctrl/⌘+S、版本冲突保留缓冲、未保存提示，五类目标位置的文件导入。
3. **协议设计**：共享模型配置、连接探测/模型列表、任务画像与自然语言需求、父代 A/B、预览/真实生成、自修复配置和结果预览。
4. **验证沙箱**：严格/兼容模式、种子/规模/精度配置、阶段判定、完整输出语义和通信来源、候选比较及历史证据。
5. **自动迭代**：父代池、质量与通信选择目标、最低通过率、预算和停止条件、冻结后的独立验证、轮次结果、任务历史及重试。
6. **实验分析**：配置化实验、开发/验证/盲测流水线、原始结果审计与报告重建、敏感度和演化绘图。
7. **统计基准**：实验类型、任务、分布、规模、扰动和通信轴筛选；同场景比较、置信区间、资格排除原因、逐 Seed 原始证据、基准执行和候选导入。
8. **实验产物**：检索/分类/分页，CSV、JSON、文本、图片、HTML/PDF 预览及下载。
9. **运行审计**：服务器任务历史、取消/重试、任务日志与结果、候选谱系及数据库记录。

本轮同时修正图片预览后缀和 API 类型不一致、快速切换统计过滤条件的旧响应覆盖，以及确认放弃修改后缓存页面仍保留脏缓冲的问题。

## 行为约定

- 默认地址为 http://127.0.0.1:8765；/ui/ 也是新版入口，/legacy 保留旧工作台。
- 新版需先构建 dist；运行时只需 Python，无需另开 Node 服务。未构建时根路径保留旧版兼容行为。
- 密钥仅保留在浏览器页面内存，路由切换共享，刷新即清除；不保存到 localStorage/sessionStorage。
- 后台任务统一轮询，切页不重复创建轮询器；短暂断网继续重试；刷新从服务器历史恢复。停止是否完成以服务器状态为准。
- 文件保存沿用 SHA-256 revision 和 409 冲突保护；冲突不覆盖磁盘、不丢弃输入。
- 统计结果、选择资格、置信区间和通信成本由后端计算；前端不改变算法或重新推断谱系。
- 新版上传集中在场景与代码，逐文件导入；旧版的批量拖放、代码高亮等增强交互保留在 /legacy，不应宣称所有旧界面交互逐项一致。
