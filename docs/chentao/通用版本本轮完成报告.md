# generic-v1 本轮完成报告

> 基线：`34bca808db848ad5ee6bfd44bf53fd8b4b27e2bf`  
> 目标：把上一版统计协议专项成果收敛为可继续轮流迭代的通用版本。

## 1. 本轮完成内容

### 任务通用化

- 新增 `generic_tasks/` 任务画像注册表。
- 统一 `statistical_metric`、`legacy_truth`、`execution_and_output_contract` 三类语义范围。
- `custom_task` 只验证执行/输出契约，不再伪造 accuracy。
- 众数/集合命中改为精确集合结果，同时保留 precision、recall、F1、Jaccard。

### 协议通用化

- 新增 `generic_protocol/` 统一 `run_many` 适配层。
- 新增 `StatisticsProtocolAdapter` 和 `LegacyProtocolAdapter`。
- 传统协议没有真实通信事件时标记 `cost_status=missing`，不进入通信 Pareto。
- 新增自由 Python 协议的独立子进程执行、超时和异常隔离。
- AI 生成候选写入统一 `<协议名>.candidate.json` provenance 记录。

### 实验通用化

- 新增配置化 `benchmark/run_config.py`。
- 新增 `benchmark/configs/smoke.json`、`final.json`。
- 输出 `results.json`、`summary.csv`、`profile_support.json`、`manifest.json`。
- Pareto 改为按 task、distribution、size、扰动和 split 分组。
- 摘要新增 `execution_success_rate`、`quality_pass_rate_successes`、`overall_pass_rate`。

### 交付通用化

- 新增 `python -m tools.verify` 一键验证。
- 新增 `requirements.txt`。
- 新增本报告、接口基线文档和 `CHANGELOG.md`。
- 新增 `tasks/lessons.md`，记录三人轮换时的复用规则。

## 3. 版本前后状态

| 维度 | 上一版 `34bca80` | 本轮 `generic-v1` |
|---|---|---|
| 任务 | 四个统计任务 + 文本自定义 | 统一任务画像注册表和语义范围 |
| 协议 | 统计 `run_many` 与传统 `execute` 分离 | 统一 adapter 接口 |

| 指标 | `quality_pass_rate` 口径混合 | 区分执行成功、成功样本质量、总体通过 |

| 交付 | 统计专项文档 | 通用接口、一键验证、版本和交接文档 |

## 4. 当前边界

本轮完成的是**平台机制通用化**，不表示算法已经覆盖任意 RFID 任务。

仍不包括：

- 真实读写器和 EPC C1G2 硬件验证；
- 真实时延、误码和能耗测量；
- 信息隔离/隐私证明；
- H3 演化质量实验；
- 任意业务自定义任务的自动准确率评价；
- 连续物理量、多属性联合任务的完整协议实现。
