## 三、测试任务画像和候选溯源

### 1. 打开“Prompt 与 AI”

设置：

- 场景：`test`
- 任务画像：`任意自定义任务`
- 父代 A：`ModeQuerySEM`
- 父代 B：`ModeQueryTKQ`
- 协议名：`GenericV1CustomCheck`
- 目标世代：`generation_0`
- 验证标签数：`120`
- 修复轮数：`1`

自定义任务填写：

```text
统计标签 price 的 90 分位数，返回 [estimated_p90]，误差不超过 5%。
```

### 2. 先点击“预览生成任务”

确认：

- Prompt 中包含完整自定义任务文本；
- 显示目标协议路径；
- 不调用模型；
- 不创建 `.py` 协议文件。

### 3. 配置模型并生成

填写现有 OpenAI 兼容模型的 URL、模型名和 API Key，点击：

```text
检查模型是否可用
```

通过后点击：

```text
生成协议代码
```

观察后台日志，确认出现类似：

```text
已写入候选协议
正在执行协议物理约束、任务烟测和信息隔离验证
子进程执行
```

无论生成成功还是失败，都应保留验证报告和失败原因。

### 4. 打开“场景与代码”

选择：

```text
test / generation_0
```

确认存在：

```text
GenericV1CustomCheck.py
GenericV1CustomCheck.candidate.json
```

打开 `.candidate.json`，确认包含：

```text
candidate_id
protocol_name
candidate_type
parents
task_profile
prompt_hash
response_hash
model
source_hash
validation_result
benchmark_result
status
```

确认文件中没有 API Key。


- 物理约束报告可查看；
