# 版本演进说明

## V0：`e74d09c`

RFID 协议自优化基础平台：场景资产、Prompt/LLM 生成、验证、批量测试、基础实验和 Web 工作台。任务主线偏众数查询，实验口径和接口尚未统一。

## V0.1：`34bca80`

统计协议专项增强版：

- Web AI 网关配置；
- 自定义任务文本；
- `stat_protocols` 统计协议；
- `benchmark` 可复现实验；
- 统计证据看板、真实候选记录和交付材料。

限制：传统 `IProtocol.execute` 与统计 `run_many` 仍分离，实验入口偏固定，自定义任务不进入统一评价。

## V1.0：`generic-v1`（本轮目标/工作区实现）

通用可迭代版本：

- `generic_tasks` 任务画像注册表；
- `generic_protocol` 统一适配层；
- 统一候选 provenance；
- 自由 Python 子进程隔离；
- 配置化 benchmark runner；
- 同场景 Pareto；
- `python -m tools.verify`；
- 版本、交接和结项证据文档。

范围限定：这是软件机制通用化，不代表硬件、隐私证明、H3 演化效果或任意业务 accuracy 已完成。
