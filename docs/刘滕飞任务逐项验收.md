## 直接查看与复现

打开 <http://127.0.0.1:8765/#statistics>。初始显示均值、多峰、1k标签；可切换六类实验集、任务、分布、规模、扰动和bits/slots/rounds。

点击图点或协议名查看逐seed原始结果、真值/估计、dataset hash、复核轨迹和失败原因。右侧实验资产可预览/下载；交付核对、算法报告、机制表和复现命令集中在[项目README第3.8节](../README.md)。

```powershell
cd code_add
python -m benchmark.suite --llm-candidate Experiments/stat_protocols/llm/290537f3a8314c0b933ce4063b95f79f/candidate.json --output-dir Experiments/stat_protocols
python -m unittest course_project.test_statistics_service course_project.test_stat_protocols course_project.test_ai_configuration course_project.test_infrastructure course_project.test_course_project -q
```

独立结果目录按main/ablation/composite/sensitivity/robustness/blind划分。仿真测量缓存用于节省本地计算，但每个方法仍按自身帧事件收费，不将缓存视为通信优化。

## 真实LLM实测补充

经用户授权复用本机Pixel连接，2026-10-29生成一份真实候选：`rounds=3`、`slots_per_value=128`、`threshold=1.75`。原始[提示词](../code_add/Experiments/stat_protocols/llm/290537f3a8314c0b933ce4063b95f79f/prompt.txt)、[响应](../code_add/Experiments/stat_protocols/llm/290537f3a8314c0b933ce4063b95f79f/response.txt)和[候选证据](../code_add/Experiments/stat_protocols/llm/290537f3a8314c0b933ce4063b95f79f/candidate.json)已交付，可通过这些链接或项目README查看。

四个任务各300条评价均执行成功；均值/方差/基数质量达标率均为93.33%，Top-k完整匹配达标率35.67%、平均F1为0.6811。这是跨场景描述性汇总，单场景95%CI须查main_cases.csv；执行成功不代表精度达标。20个seed评估同一候选的数据鲁棒性，不代表20次模型生成；不推导LLM整体能力或H3演化效果。

在主实验选择“真实LLM单次候选”图点或协议名，可查看20条单场景原始结果；展开seed记录可核对候选ID与模型。项目README提供模型原始响应链接。网页刷新后自动保留已交付候选，点击重跑无需再次生成模型记录。

## 三分钟演示

1. 0:00–0:40：打开统计基准，切换均值/方差/基数/Top-k，展示bits和slots差别。
2. 0:40–1:20：选择H1三任务共享，对比single_serial与shared_sketch，解释一次采集费用不会按任务重复相加。

4. 2:00–2:35：选择缺失或盲测，点击协议，展开一个seed的原始证据；查看失败候选。
5. 2:35–3:00：打开项目README中的交付报告、机制表和复现命令，说明真实LLM与跨成员集成的状态。
