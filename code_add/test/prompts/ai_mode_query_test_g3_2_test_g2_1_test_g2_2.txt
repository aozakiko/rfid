提示词：任务: 作为一名资深的 RFID 协议设计与优化专家，请基于给定的两个父代 RFID 协议（不要引入任何其他父代协议），创造一个全新的、功能完整的子代协议。

平台背景：
本平台定位为“面向多维统计场景的 RFID 协议自优化 Web 平台”。生成协议不应被限定为众数查询，而应能根据后续任务画像扩展到均值、方差、标准差、中位数、分位数、基数估计、缺失盘点、热点检测等 RFID/物联网统计任务。请把父代协议中的时隙帧、碰撞利用、位图/草图估计、自适应帧长、分批验证、提前终止、分层抽样等机制抽象成可复用的“协议基因”。

核心设计准则（必须严格遵守）：
1. 强制交叉（Mandatory Crossover）：新协议的设计必须体现对父代 A 和父代 B 核心思想的深度融合，而不是简单复制其中一个父代。
2. 强制突变（Mandatory Mutation）：在融合父代思想的基础上，新协议必须引入至少一项父代中没有的优化机制，例如动态帧长、分层采样、草图估计、置信区间修正、候选桶重检、早停策略或多阶段校验。
3. 任务适配（Task Adaptation）：请等待并服从后续追加的任务画像。若任务画像要求单值估计，execute() 应返回单元素 list；若任务画像要求候选集合，execute() 应返回保守且相关的候选 list。
4. 准确率与通信开销平衡：优先保证逻辑正确性，同时控制 reader 发送位数、标签响应时隙数和多阶段开销。
5. 信息隔离原则（Information Isolation Principle）：
   - 读写器（Reader）：读写器默认已知环境中所有标签 ID 列表作为全局背景信息。协议执行期间，读写器可以广播参数，但它的所有决策和分析只能依据：1) 自己广播过的历史参数；2) 从天线接收到的匿名聚合信号（frame/bit stream/collision sketch）；3) 已知标签 ID 列表。严禁在读写器决策逻辑中直接或间接访问单个标签私有属性，例如 tag.price。
   - 标签（Tag）：标签响应只能依据：1) 自身私有数据（ID 和数值属性）；2) 当前读写器广播指令。标签不得读取其他标签信息或全局通信结果。
6. 执行时间计算：代码中必须计算协议执行时间，推荐公式为：
   TotalTime = T_reader + T_tag + T_overhead
   T_reader (ms) = total_bits_sent_by_reader * 0.025
   T_tag (ms) = total_slots * bits_per_slot * 0.4
   T_overhead (ms) = (total_frames - 1) * 30

执行步骤：
第一步：交叉（Crossover）- 融合父代基因
请分析父代 A 和父代 B 的 Python 代码，从它们的帧结构、响应规则、估计逻辑、终止条件和验证数据中提取可复用设计，生成结构完整且逻辑自洽的初始子代协议。

第二步：突变（Mutation）- 引入创新优化

4. 增加面向多维统计任务的参数化算子，使同一协议骨架可服务不同统计目标。

class test_g2_1(IProtocol):
    """
    面向离散属性众数/多众数查询的混合式 RFID 协议。
    设计目标：
    1) 通过批量位图并行筛选候选；
    2) 通过 SOG/碰撞草图进行多轮精估；
    3) 通过候选重检与置信边界进行保守输出；
    4) 保持协议骨架可扩展到其他统计任务。
    """

    def _safe_attr_value(self, tag: Tag) -> Any:
        return tag.__dict__.get("price")

    def _estimate_count_from_zero(self, zero_count: int, frame_size: int) -> float:
        if frame_size <= 0:
            return 0.0
        if zero_count >= frame_size:
            return 0.0
        if zero_count <= 0:
            return float(frame_size) * 3.0
        ratio = zero_count / float(frame_size)
        return -frame_size * math.log(ratio)

    def _leading_zero_count(self, value: int, bit_len: int) -> int:
        if bit_len <= 0:
            return 0
        count = 0
        for i in range(bit_len - 1, -1, -1):
            if ((value >> i) & 1) == 0:
                count += 1
            else:
                break
        return count

    def _estimate_count_from_sog_or(self, combined_signal: int, bits_per_slot: int, omega: float = 1.2897) -> float:
        if bits_per_slot <= 0:
            return 0.0
        lz = self._leading_zero_count(combined_signal, bits_per_slot)
        return omega * (2 ** lz)

    def _build_sog_string(self, tag_id: Any, seed: int, sog_length: int) -> int:
        rnd = simple_hash(tag_id, seed)
        mu = 0
        found_one = False
        for i in range(sog_length - 1, -1, -1):
            if (rnd >> i) & 1:
                found_one = True
                break
            mu += 1
        if not found_one:
            mu = sog_length
        if mu >= sog_length:
            return 0
        return 1 << (sog_length - 1 - mu)

    def _adaptive_frame_size(self, candidate_count: int, scale: int, minimum: int, maximum: int) -> int:
        base = max(minimum, candidate_count * scale)
        power = 1
        while power < base and power < maximum:
            power <<= 1
        return min(maximum, max(minimum, power))

    def _batch_values(self, values: List[int], batch_size: int) -> List[List[int]]:
        if batch_size <= 0:
            return []
        return [values[i:i + batch_size] for i in range(0, len(values), batch_size)]

    def _select_top_with_ties(self, scores: Dict[int, float], limit: int) -> List[int]:
        if not scores or limit <= 0:
            return []
        ordered = sorted(scores.items(), key=lambda x: (-x[1], x[0]))
        if limit >= len(ordered):
            return [k for k, _ in ordered]
        threshold = ordered[limit - 1][1]
        selected = [k for k, v in ordered if v >= threshold]
        return selected[:max(limit + 2, limit)]

    def _select_conservative_candidates(
        self,
        scores: Dict[int, float],
        max_candidates: int = 3,
        rel_threshold: float = 0.93,
        abs_gap_ratio: float = 0.08
    ) -> List[int]:
        positive_items = [(k, v) for k, v in scores.items() if v is not None and v > 0]
        if not positive_items:
            return []
        positive_items.sort(key=lambda x: (-x[1], x[0]))
        top_score = positive_items[0][1]
        if top_score <= 0:
            return []

        selected = []
        abs_gap = max(1.0, top_score * abs_gap_ratio)
        for val, score in positive_items:
            if score >= top_score * rel_threshold and (top_score - score) <= abs_gap:
                selected.append(val)
            if len(selected) >= max_candidates:
                break

        if not selected:
            selected = [positive_items[0][0]]
        return sorted(selected)

    def _tag_response_sem_batch(
        self,
        tags: List[Tag],
        batch_values: List[int],
        seed: int,
        frame_size: int
    ) -> Frame:
        value_to_bit = {v: i for i, v in enumerate(batch_values)}
        target_set = set(batch_values)
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=len(batch_values))
        for tag in tags:
            value = self._safe_attr_value(tag)
            if value not in target_set:
                continue
            slot_id = simple_hash(tag.id, seed) % frame_size
            bit_pos = value_to_bit[value]
            physical_frame.aggregate(slot_id, 1 << bit_pos)
        return physical_frame

    def _tag_response_value_mapped_sog_batch(
        self,
        tags: List[Tag],
        batch_values: List[int],
        seed: int,
        frame_size: int,
        bits_per_slot: int
    ) -> Frame:
        target_set = set(batch_values)
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=bits_per_slot)
        for tag in tags:
            value = self._safe_attr_value(tag)
            if value not in target_set:
                continue
            slot_seed = simple_hash(seed, value)
            slot_id = simple_hash(tag.id, slot_seed) % frame_size
            sog_seed = simple_hash(seed, simple_hash(value, 0x9E3779B1))
            sog = self._build_sog_string(tag.id, sog_seed, bits_per_slot)
            physical_frame.aggregate(slot_id, sog)
        return physical_frame

    def _tag_response_global_sog(
        self,
        tags: List[Tag],
        seed: int,
        frame_size: int,
        bits_per_slot: int
    ) -> Frame:
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=bits_per_slot)
        for tag in tags:
            value = self._safe_attr_value(tag)
            if value is None:
                continue
            sog = self._build_sog_string(tag.id, seed, bits_per_slot)
            slot_id = simple_hash(value, seed) % frame_size
            physical_frame.aggregate(slot_id, sog)
        return physical_frame

    def _analyze_sem_batch(self, frame: Frame, batch_values: List[int], frame_size: int) -> Dict[int, float]:
        estimates = {}
        for bit_pos, value in enumerate(batch_values):
            ones = 0
            for slot_data in frame.slots:
                ones += (slot_data >> bit_pos) & 1
            zeros = frame_size - ones
            estimates[value] = self._estimate_count_from_zero(zeros, frame_size)
        return estimates

    def _analyze_value_mapped_sog_batch(
        self,
        frame: Frame,
        batch_values: List[int],
        frame_size: int,
        bits_per_slot: int,
        seed: int
    ) -> Dict[int, float]:
        estimates = {}
        slot_to_values = defaultdict(list)
        for value in batch_values:
            slot_seed = simple_hash(seed, value)
            slot_id = simple_hash(value, slot_seed) % frame_size
            slot_to_values[slot_id].append(value)

        for slot_id, values in slot_to_values.items():
            if len(values) == 1:
                value = values[0]
                est = self._estimate_count_from_sog_or(frame.slots[slot_id], bits_per_slot)
                estimates[value] = est

        for value in batch_values:
            if value not in estimates:
                estimates[value] = 0.0
        return estimates

    def _run_sem_stage(
        self,
        tags: List[Tag],
        values: List[int],
        batch_size: int,
        frame_size: int
    ) -> Tuple[Dict[int, float], int, int, int, List[int], List[int]]:
        total_frames = 0
        total_reader_bits = 0
        total_slots = 0
        stage_frame_sizes = []
        stage_bits_per_slot = []
        estimates = {v: 0.0 for v in values}

        batches = self._batch_values(values, batch_size)
        for batch in batches:
            if not batch:
                continue
            seed = generate_random_seed()
            total_frames += 1
            total_slots += frame_size
            stage_frame_sizes.append(frame_size)
            stage_bits_per_slot.append(len(batch))

            total_reader_bits += (
                seed.bit_length() +
                frame_size.bit_length() +
                len(batch).bit_length() +
                len(batch) * max(1, max(abs(int(x)) for x in batch).bit_length() if batch else 1)
            )

            frame = self._tag_response_sem_batch(tags, batch, seed, frame_size)
            batch_est = self._analyze_sem_batch(frame, batch, frame_size)
            for v, est in batch_est.items():
                estimates[v] = est

        return estimates, total_frames, total_reader_bits, total_slots, stage_frame_sizes, stage_bits_per_slot

    def _run_refine_stage(
        self,
        tags: List[Tag],
        candidates: List[int],
        frame_size: int,
        bits_per_slot: int,
        rounds: int,
        batch_size: int
    ) -> Tuple[Dict[int, float], Dict[int, int], int, int, int, List[int], List[int]]:
        aggregated = defaultdict(float)
        seen = defaultdict(int)
        unique_hits = defaultdict(int)

        total_frames = 0
        total_reader_bits = 0
        total_slots = 0
        stage_frame_sizes = []
        stage_bits_per_slot = []

        batches = self._batch_values(candidates, batch_size)
        for _ in range(rounds):
            for batch in batches:
                if not batch:
                    continue
                seed = generate_random_seed()
                total_frames += 1
                total_slots += frame_size
                stage_frame_sizes.append(frame_size)
                stage_bits_per_slot.append(bits_per_slot)

                total_reader_bits += (
                    seed.bit_length() +
                    frame_size.bit_length() +
                    bits_per_slot.bit_length() +
                    len(batch).bit_length()
                )

                frame = self._tag_response_value_mapped_sog_batch(
                    tags=tags,
                    batch_values=batch,
                    seed=seed,
                    frame_size=frame_size,
                    bits_per_slot=bits_per_slot
                )
                batch_est = self._analyze_value_mapped_sog_batch(
                    frame=frame,
                    batch_values=batch,
                    frame_size=frame_size,
                    bits_per_slot=bits_per_slot,
                    seed=seed
                )

                for v in batch:
                    est = batch_est.get(v, 0.0)
                    if est > 0:
                        aggregated[v] += est
                        seen[v] += 1
                        unique_hits[v] += 1

        final_estimates = {}
        for v in candidates:
            if seen[v] > 0:
                base_est = aggregated[v] / seen[v]
                confidence_bonus = 1.0 + min(0.18, 0.03 * unique_hits[v])
                final_estimates[v] = base_est * confidence_bonus
            else:
                final_estimates[v] = 0.0

        return final_estimates, unique_hits, total_frames, total_reader_bits, total_slots, stage_frame_sizes, stage_bits_per_slot

    def _run_verify_stage(
        self,
        tags: List[Tag],
        candidates: List[int],
        frame_size: int,
        bits_per_slot: int,
        rounds: int
    ) -> Tuple[Dict[int, float], List[int], int, int, int, List[int], List[int]]:
        sog_stats = {v: {"sum_est": 0.0, "rounds": 0, "unique_hits": 0} for v in candidates}
        round_unique_counts = []

        total_frames = 0
        total_reader_bits = 0
        total_slots = 0
        stage_frame_sizes = []
        stage_bits_per_slot = []

        for _ in range(rounds):
            seed = generate_random_seed()
            total_frames += 1
            total_slots += frame_size
            stage_frame_sizes.append(frame_size)
            stage_bits_per_slot.append(bits_per_slot)

            total_reader_bits += (
                seed.bit_length() +
                frame_size.bit_length() +
                bits_per_slot.bit_length()
            )

            frame = self._tag_response_global_sog(tags, seed, frame_size, bits_per_slot)

            slot_to_candidates = defaultdict(list)
            for v in candidates:
                slot_to_candidates[simple_hash(v, seed) % frame_size].append(v)

            unique_cnt = 0
            for slot_idx, vals in slot_to_candidates.items():
                if len(vals) == 1:
                    unique_cnt += 1
                    v = vals[0]
                    est = self._estimate_count_from_sog_or(frame.slots[slot_idx], bits_per_slot)
                    sog_stats[v]["sum_est"] += est
                    sog_stats[v]["rounds"] += 1
                    sog_stats[v]["unique_hits"] += 1
            round_unique_counts.append(unique_cnt)

        verify_estimates = {}
        for v in candidates:
            if sog_stats[v]["rounds"] > 0:
                base = sog_stats[v]["sum_est"] / sog_stats[v]["rounds"]
                verify_estimates[v] = base * (1.0 + min(0.15, 0.025 * sog_stats[v]["unique_hits"]))
            else:
                verify_estimates[v] = 0.0

        return verify_estimates, round_unique_counts, total_frames, total_reader_bits, total_slots, stage_frame_sizes, stage_bits_per_slot

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        all_values = list(range(price_min, price_max + 1))
        domain_size = len(all_values)

        if domain_size <= 0:
            verification_data = {
                "frame_size": 1,
                "bits_per_slot": 1,
                "stage_frame_sizes": [],
                "stage_bits_per_slot": [],
                "total_frames": 0
            }
            return [], 0, 0.0, verification_data

        total_frames = 0
        total_bits_sent_by_reader = 0
        total_slots = 0

        stage_frame_sizes = []
        stage_bits_per_slot = []
        stage_names = []

        # --- 交叉部分：融合父代 A 的“分批位图并行估计 + 自适应帧长 + 候选重检”思想与父代 B 的“SOG/碰撞草图多轮精估 + 唯一映射时隙解析”思想 ---
        stage1_batch_size = min(128, max(8, domain_size if domain_size < 128 else 128))
        stage1_frame_size = self._adaptive_frame_size(stage1_batch_size, 8, 256, 32768)

        sem_estimates, frames, reader_bits, slots, sfs, sbps = self._run_sem_stage(
            tags=tags,
            values=all_values,
            batch_size=stage1_batch_size,
            frame_size=stage1_frame_size
        )
        total_frames += frames
        total_bits_sent_by_reader += reader_bits
        total_slots += slots
        stage_frame_sizes.extend(sfs)
        stage_bits_per_slot.extend(sbps)
        stage_names.extend(["sem_batch"] * len(sfs))

        pre_candidate_limit = min(10, max(3, int(math.sqrt(max(1, domain_size))) + 1))
        pre_candidates = self._select_top_with_ties(sem_estimates, pre_candidate_limit)
        pre_candidates = self._select_conservative_candidates(
            {v: sem_estimates.get(v, 0.0) for v in pre_candidates},
            max_candidates=min(8, pre_candidate_limit),
            rel_threshold=0.87,
            abs_gap_ratio=0.18
        ) if pre_candidates else []

        if not pre_candidates:
            T_reader = total_bits_sent_by_reader * 0.025
            avg_bits_per_slot = max(1, int(sum(stage_bits_per_slot) / len(stage_bits_per_slot))) if stage_bits_per_slot else 1
            T_tag = total_slots * avg_bits_per_slot * 0.4
            T_overhead = (total_frames - 1) * 30 if total_frames > 1 else 0.0
            verification_data = {
                "frame_size": stage1_frame_size,
                "bits_per_slot": stage1_batch_size,
                "stage_frame_sizes": stage_frame_sizes,
                "stage_bits_per_slot": stage_bits_per_slot,
                "stage_names": stage_names,
                "total_frames": total_frames,
                "stage1_sem_estimates": sem_estimates,
                "early_stop": True
            }
            return [], 0, T_reader + T_tag + T_overhead, verification_data

        refine_batch_size = min(32, max(2, len(pre_candidates)))
        refine_bits_per_slot = min(64, max(16, int(math.ceil(math.log2(max(4, len(tags) + 1)))) + 8))
        refine_frame_size = self._adaptive_frame_size(len(pre_candidates), 32, 512, 32768)
        refine_rounds = 2 if len(pre_candidates) <= 4 else 3

        refined_estimates, unique_hits, frames, reader_bits, slots, sfs, sbps = self._run_refine_stage(
            tags=tags,
            candidates=pre_candidates,
            frame_size=refine_frame_size,
            bits_per_slot=refine_bits_per_slot,
            rounds=refine_rounds,
            batch_size=refine_batch_size
        )
        total_frames += frames
        total_bits_sent_by_reader += reader_bits
        total_slots += slots
        stage_frame_sizes.extend(sfs)
        stage_bits_per_slot.extend(sbps)
        stage_names.extend(["sog_refine_batch"] * len(sfs))

        fused_scores = {}
        for v in pre_candidates:
            sem_score = sem_estimates.get(v, 0.0)
            refine_score = refined_estimates.get(v, 0.0)
            if refine_score > 0:
                fused_scores[v] = 0.42 * sem_score + 0.58 * refine_score
            else:
                fused_scores[v] = 0.82 * sem_score

        ranked_fused = sorted(fused_scores.items(), key=lambda x: (-x[1], x[0]))
        top_verify_candidates = [v for v, _ in ranked_fused[:min(5, len(ranked_fused))]]

        # --- 突变部分：引入“动态置信边界早停 + 不确定候选自适应重检”全新机制 ---
        # 若前两名差距足够大则提前终止；否则仅对少量不确定候选做第三阶段重检。
        need_verify = True
        early_stop = False
        if len(ranked_fused) >= 2 and ranked_fused[0][1] > 0:
            top_score = ranked_fused[0][1]
            second_score = ranked_fused[1][1]
            margin_ratio = (top_score - second_score) / max(top_score, 1e-9)
            top_unique = unique_hits.get(ranked_fused[0][0], 0)
            second_unique = unique_hits.get(ranked_fused[1][0], 0)
            if margin_ratio >= 0.16 and top_unique >= max(1, second_unique):
                need_verify = False
                early_stop = True
        elif len(ranked_fused) == 1:
            need_verify = False
            early_stop = True

        verify_estimates = {}
        round_unique_counts = []
        final_scores = dict(fused_scores)

        if need_verify and top_verify_candidates:
            verify_bits_per_slot = min(64, max(16, refine_bits_per_slot))
            verify_frame_size = self._adaptive_frame_size(len(top_verify_candidates), 64, 512, 32768)
            verify_rounds = 2 if len(top_verify_candidates) <= 3 else 3

            verify_estimates, round_unique_counts, frames, reader_bits, slots, sfs, sbps = self._run_verify_stage(
                tags=tags,
                candidates=top_verify_candidates,
                frame_size=verify_frame_size,

            )
            total_frames += frames
            total_bits_sent_by_reader += reader_bits
            total_slots += slots
            stage_frame_sizes.extend(sfs)
            stage_bits_per_slot.extend(sbps)
            stage_names.extend(["sog_verify_global"] * len(sfs))

            for v in top_verify_candidates:
                sem_score = sem_estimates.get(v, 0.0)
                refine_score = refined_estimates.get(v, 0.0)
                verify_score = verify_estimates.get(v, 0.0)
                if verify_score > 0 and refine_score > 0:
                    final_scores[v] = 0.22 * sem_score + 0.33 * refine_score + 0.45 * verify_score
                elif verify_score > 0:
                    final_scores[v] = 0.38 * sem_score + 0.62 * verify_score
                else:
                    final_scores[v] = 0.46 * sem_score + 0.54 * refine_score

        estimated_values = self._select_conservative_candidates(
            final_scores,
            max_candidates=2 if early_stop else 3,
            rel_threshold=0.94 if need_verify else 0.91,
            abs_gap_ratio=0.10 if need_verify else 0.14
        )

        if not estimated_values and ranked_fused:
            estimated_values = [ranked_fused[0][0]]

        metric = 0
        if estimated_values:
            metric = int(math.ceil(max(final_scores.get(v, 0.0) for v in estimated_values)))

        T_reader = total_bits_sent_by_reader * 0.025
        avg_bits_per_slot = max(1, int(sum(stage_bits_per_slot) / len(stage_bits_per_slot))) if stage_bits_per_slot else 1
        T_tag = total_slots * avg_bits_per_slot * 0.4
        T_overhead = (total_frames - 1) * 30 if total_frames > 1 else 0.0
        total_time_ms = T_reader + T_tag + T_overhead

        verification_data = {
            "frame_size": stage_frame_sizes[0] if stage_frame_sizes else stage1_frame_size,
            "bits_per_slot": stage_bits_per_slot[0] if stage_bits_per_slot else stage1_batch_size,
            "stage_frame_sizes": stage_frame_sizes,
            "stage_bits_per_slot": stage_bits_per_slot,
            "stage_names": stage_names,
            "total_frames": total_frames,
            "stage1_sem_estimates": sem_estimates,
            "refined_estimates": refined_estimates,
            "verify_estimates": verify_estimates,
            "final_scores": final_scores,
            "pre_candidates": pre_candidates,
            "top_verify_candidates": top_verify_candidates,
            "refine_unique_hits": dict(unique_hits),
            "verify_round_unique_counts": round_unique_counts,

                "multi_stage_filtering": True,

class test_g2_2(IProtocol):
    """
    面向离散属性众数/多众数查询的混合式 RFID 协议。
    设计目标：
    1) 继承批量位图并行估计基因；
    2) 继承逐级候选筛选与复核基因；
    3) 通过匿名聚合帧完成众数/多众数保守输出；
    4) 为后续扩展到多种统计任务保留协议骨架。
    """

    def _safe_attr_value(self, tag: Tag) -> Any:
        return tag.__dict__.get("price")

    def _leading_zero_index(self, value: int, width: int) -> int:
        for i in range(width):
            bit = (value >> (width - 1 - i)) & 1
            if bit == 1:
                return i
        return width

    def _build_sog_bit(self, tag_id: Any, seed: int, sog_length: int) -> int:
        rnd = simple_hash(tag_id, seed)
        idx = self._leading_zero_index(rnd, sog_length)
        if idx >= sog_length:
            return 0
        return 1 << (sog_length - 1 - idx)

    def _tag_response_bitmap(
        self,
        tag: Tag,
        target_set: set,
        value_to_bit: Dict[int, int],
        seed: int,
        frame_size: int
    ):
        v = self._safe_attr_value(tag)
        if v not in target_set:
            return None
        slot_id = simple_hash(tag.id, seed) % frame_size
        return slot_id, (1 << value_to_bit[v])

    def _tag_response_sog(
        self,
        tag: Tag,
        target_set: set,
        value_to_bit: Dict[int, int],
        seed: int,
        frame_size: int,
        sog_seed_base: int,
        sog_length: int
    ):
        v = self._safe_attr_value(tag)
        if v not in target_set:
            return None
        slot_seed = simple_hash(seed, v ^ 0x9E3779B1)
        slot_id = simple_hash(tag.id, slot_seed) % frame_size
        bit_pos = value_to_bit[v]
        sog_seed = simple_hash(sog_seed_base, v)
        sog_marker = self._build_sog_bit(tag.id, sog_seed, sog_length)
        strength = 1 if sog_marker != 0 else 0
        return slot_id, (strength << bit_pos)

    def _simulate_batch_frame(
        self,
        tags: List[Tag],
        batch: List[int],
        frame_size: int,
        seed: int,
        use_sog: bool = False,
        sog_length: int = 16
    ) -> Frame:
        bits_per_slot = max(1, len(batch))
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=bits_per_slot)
        value_to_bit = {v: i for i, v in enumerate(batch)}
        target_set = set(batch)
        sog_seed_base = simple_hash(seed, 0xA5A5A5A5)

        for tag in tags:
            if use_sog:
                resp = self._tag_response_sog(
                    tag, target_set, value_to_bit, seed, frame_size, sog_seed_base, sog_length
                )
            else:
                resp = self._tag_response_bitmap(
                    tag, target_set, value_to_bit, seed, frame_size
                )
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _simulate_single_value_frame(
        self,
        tags: List[Tag],
        target_value: int,
        frame_size: int,
        seed: int
    ) -> Frame:
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=1)
        target_set = {target_value}
        value_to_bit = {target_value: 0}
        for tag in tags:
            resp = self._tag_response_bitmap(tag, target_set, value_to_bit, seed, frame_size)
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _estimate_cardinality(self, logical_bits: List[int], frame_size: int) -> float:
        occupied = sum(logical_bits)
        zeros = frame_size - occupied
        if zeros == frame_size:
            return 0.0
        if zeros == 0:
            return float(frame_size) * 2.0
        return -frame_size * math.log(zeros / frame_size)

    def _estimate_with_correction(
        self,
        logical_bits: List[int],
        frame_size: int,
        use_sog: bool = False
    ) -> Tuple[float, Dict[str, float]]:
        occupied = sum(logical_bits)
        zeros = frame_size - occupied
        raw = self._estimate_cardinality(logical_bits, frame_size)
        occupancy_ratio = occupied / frame_size if frame_size > 0 else 0.0
        if use_sog:
            correction = 1.0 + 0.12 * occupancy_ratio
        else:
            correction = 1.0
        return raw * correction, {
            "occupied": float(occupied),
            "zeros": float(zeros),
            "occupancy_ratio": float(occupancy_ratio),
            "correction": float(correction),
        }

    def _adaptive_frame_size(self, candidate_count: int, stage: str) -> int:
        candidate_count = max(1, candidate_count)
        if stage == "coarse":
            base = max(64, min(2048, candidate_count * 4))
        elif stage == "refine":
            base = max(256, min(8192, candidate_count * 32))
        else:
            base = max(512, min(16384, candidate_count * 96))
        power = 1
        while power < base and power < 32768:
            power <<= 1
        return min(32768, max(64, power))

    def _chunk_values(self, values: List[int], batch_size: int) -> List[List[int]]:
        return [values[i:i + batch_size] for i in range(0, len(values), batch_size)]

    def _run_parallel_stage(
        self,
        tags: List[Tag],
        target_values: List[int],
        frame_size: int,
        batch_size: int,
        rounds: int,
        use_sog: bool,
        sog_length: int
    ) -> Tuple[Dict[int, float], Dict[int, Dict[str, float]], Dict[str, int]]:
        aggregated: Dict[int, float] = {}
        seen: Dict[int, int] = {}
        diagnostics: Dict[int, Dict[str, float]] = {}
        total_frames = 0
        total_reader_bits = 0
        total_slots = 0
        bits_per_slot = max(1, min(batch_size, 256))

        batches = self._chunk_values(target_values, batch_size)

        for _ in range(rounds):
            for batch in batches:
                if not batch:
                    continue
                seed = generate_random_seed()
                total_frames += 1
                total_reader_bits += seed.bit_length() + frame_size.bit_length() + len(batch).bit_length() + max(1, sog_length.bit_length())
                total_slots += frame_size

                physical_frame = self._simulate_batch_frame(
                    tags=tags,
                    batch=batch,
                    frame_size=frame_size,
                    seed=seed,
                    use_sog=use_sog,
                    sog_length=sog_length
                )

                for bit_pos, value in enumerate(batch):
                    logical_bits = [((slot_data >> bit_pos) & 1) for slot_data in physical_frame.slots]
                    est, info = self._estimate_with_correction(logical_bits, frame_size, use_sog=use_sog)
                    aggregated[value] = aggregated.get(value, 0.0) + est
                    seen[value] = seen.get(value, 0) + 1
                    prev = diagnostics.get(value, {"occupied": 0.0, "zeros": 0.0, "occupancy_ratio": 0.0, "correction": 0.0})
                    diagnostics[value] = {
                        "occupied": prev["occupied"] + info["occupied"],
                        "zeros": prev["zeros"] + info["zeros"],
                        "occupancy_ratio": prev["occupancy_ratio"] + info["occupancy_ratio"],
                        "correction": prev["correction"] + info["correction"],
                    }

        final_counts: Dict[int, float] = {}
        for v in target_values:
            cnt = seen.get(v, 0)
            if cnt <= 0:
                final_counts[v] = 0.0
                continue
            final_counts[v] = aggregated[v] / cnt
            d = diagnostics.get(v)
            if d is not None:
                diagnostics[v] = {
                    "occupied": d["occupied"] / cnt,
                    "zeros": d["zeros"] / cnt,
                    "occupancy_ratio": d["occupancy_ratio"] / cnt,
                    "correction": d["correction"] / cnt,
                }

        metrics = {
            "frames_used": total_frames,
            "reader_bits": total_reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": bits_per_slot,
        }
        return final_counts, diagnostics, metrics

    def _run_single_verify_stage(
        self,
        tags: List[Tag],
        candidate_values: List[int],
        frame_size: int,
        rounds: int
    ) -> Tuple[Dict[int, float], Dict[int, int], Dict[str, int]]:
        estimates: Dict[int, float] = {}
        occupied_map: Dict[int, int] = {}
        total_frames = 0
        total_reader_bits = 0
        total_slots = 0

        for value in candidate_values:
            est_acc = 0.0
            occ_acc = 0
            used = 0
            for _ in range(rounds):
                seed = generate_random_seed()
                total_frames += 1
                total_reader_bits += seed.bit_length() + frame_size.bit_length() + max(1, int(value)).bit_length() if isinstance(value, int) and value > 0 else seed.bit_length() + frame_size.bit_length() + 1
                total_slots += frame_size
                physical_frame = self._simulate_single_value_frame(tags, value, frame_size, seed)
                logical_bits = [1 if slot_data != 0 else 0 for slot_data in physical_frame.slots]
                est = self._estimate_cardinality(logical_bits, frame_size)
                est_acc += est
                occ_acc += sum(logical_bits)
                used += 1
            estimates[value] = est_acc / max(1, used)
            occupied_map[value] = int(round(occ_acc / max(1, used)))

        metrics = {
            "frames_used": total_frames,
            "reader_bits": total_reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": 1,
        }
        return estimates, occupied_map, metrics

    def _sort_desc(self, d: Dict[int, float]) -> List[Tuple[int, float]]:
        return sorted(d.items(), key=lambda kv: (-kv[1], kv[0]))

    def _select_top_with_ties(self, estimates: Dict[int, float], limit: int) -> List[int]:
        ordered = self._sort_desc(estimates)
        if not ordered:
            return []
        if len(ordered) <= limit:
            return [v for v, _ in ordered]
        threshold = ordered[limit - 1][1]
        selected = [v for v, s in ordered if s >= threshold]
        return selected[:max(limit + 2, limit)]

    def _confidence_interval_radius(self, est: float, frame_size: int, rounds: int) -> float:
        if est <= 0:
            return 0.5
        variance_proxy = max(1.0, est)
        radius = 1.2 * math.sqrt(variance_proxy / max(1, rounds))
        density_penalty = 0.02 * frame_size / max(64, frame_size)
        return radius + density_penalty

    def _conservative_multimode_decision(
        self,
        refined_counts: Dict[int, float],
        verify_counts: Dict[int, float],
        verify_frame_size: int,
        verify_rounds: int
    ) -> Tuple[List[int], float, Dict[str, Any]]:
        if not verify_counts:
            ordered_ref = self._sort_desc(refined_counts)
            if not ordered_ref:
                return [], 0.0, {"decision": "empty"}
            return [ordered_ref[0][0]], ordered_ref[0][1], {"decision": "refine_fallback"}

        ordered = self._sort_desc(verify_counts)
        best_value, best_score = ordered[0]
        best_radius = self._confidence_interval_radius(best_score, verify_frame_size, verify_rounds)
        selected = [best_value]

        # --- 交叉部分：融合父代 A 的“多轮并行统计估计/SOG 校正”思想与父代 B 的“逐级候选筛选/单值复核”思想 ---
        # --- 突变部分：引入“置信区间修正 + 异常候选重检触发 + 早停”全新机制 ---
        abnormal_gap_trigger = False
        for value, score in ordered[1:]:
            radius = self._confidence_interval_radius(score, verify_frame_size, verify_rounds)
            refined_score = refined_counts.get(value, 0.0)
            refined_best = refined_counts.get(best_value, best_score)
            overlap = (best_score - best_radius) <= (score + radius)
            refined_close = abs(refined_best - refined_score) <= max(best_radius + radius, 0.08 * max(best_score, 1.0))
            if overlap and refined_close:
                selected.append(value)
            else:
                if best_score > 0 and (best_score - score) / best_score < 0.06:
                    abnormal_gap_trigger = True
                break

        selected = sorted(selected[:3])

        decision_info = {
            "decision": "verified",
            "best_score": best_score,
            "best_radius": best_radius,
            "abnormal_gap_trigger": abnormal_gap_trigger,
            "ordered_verify_top": ordered[:5],
        }
        return selected, best_score, decision_info

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:

                extra = recheck_counts.get(v, 0.0)
                merged_verify[v] = (base * verify_rounds + extra) / (verify_rounds + 1)

            estimated_values, metric_score, decision_info = self._conservative_multimode_decision(
                refined_counts=refined_counts,
                verify_counts=merged_verify,
                verify_frame_size=recheck_frame_size,
                verify_rounds=verify_rounds + 1

            },

            "coarse_candidate_pool_size": coarse_pool_size,

            "refined_top": sorted_refined[:10],

            "occupied_slots_final": occupied_map,
            "coarse_diagnostics": {k: coarse_diag[k] for k in coarse_candidates[:min(6, len(coarse_candidates))] if k in coarse_diag},
            "refined_diagnostics": {k: refined_diag[k] for k in preliminary_verify[:min(6, len(preliminary_verify))] if k in refined_diag},
            "decision_info": decision_info,
            "extra_recheck_used": extra_recheck_used,
        }

        metric = int(math.ceil(metric_score)) if metric_score != float("inf") else int(10 ** 9)
        return list(estimated_values), metric, total_time_ms, verification_data
