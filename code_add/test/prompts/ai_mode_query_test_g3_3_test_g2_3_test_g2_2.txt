提示词：任务: 作为一名资深的 RFID 协议设计与优化专家，请基于给定的两个父代 RFID 协议（不要引入任何其他父代协议），创造一个全新的、功能完整的子代协议。

平台背景：
本平台定位为“面向多维统计场景的 RFID 协议自优化 Web 平台”。生成协议不应被限定为众数查询，而应能根据后续任务画像扩展到均值、方差、标准差、中位数、分位数、基数估计、缺失盘点、热点检测等 RFID/物联网统计任务。请把父代协议中的时隙帧、碰撞利用、位图/草图估计、自适应帧长、分批验证、提前终止、分层抽样等机制抽象成可复用的“协议基因”。

核心设计准则（必须严格遵守）：
1. 强制交叉（Mandatory Crossover）：新协议的设计必须体现对父代 A 和父代 B 核心思想的深度融合，而不是简单复制其中一个父代。
2. 强制突变（Mandatory Mutation）：在融合父代思想的基础上，新协议必须引入至少一项父代中没有的优化机制，例如动态帧长、分层采样、草图估计、置信区间修正、候选桶重检、早停策略或多阶段校验。
3. 任务适配（Task Adaptation）：请等待并服从后续追加的任务画像。若任务画像要求单值估计，execute() 应返回单元素 list；若任务画像要求候选集合，execute() 应返回保守且相关的候选 list。
4. 准确率与通信开销平衡：优先保证逻辑正确性，同时控制 reader 发送位数、标签响应时隙数和多阶段开销。
5. 信息隔离原则（Information Isolation Principle）：
   - 读写器（Reader）：读写器默认已知环境中所有标签 ID 列表作为全局背景信息。协议执行期间，读写器可以广播参数，但它的所有决策和分析只能依据：1) 自己广播过的历史参数；2) 从天线接收到的匿名聚合信号（frame/bit stream/collision sketch）；3) 已知标签 ID 列表。严禁在读写器决策逻辑中直接或间接访问单个标签私有属性，例如 tag.price。
   - 标签（Tag）：标签响应只能依据：1) 自身私有数据（ID 和数值属性）；2) 当前读写器广播指令。标签不得读取其他标签信息或全局通信结果。
6. 执行时间计算：代码中必须计算协议执行时间，推荐公式为：
   TotalTime = T_reader + T_tag + T_overhead
   T_reader (ms) = total_bits_sent_by_reader * 0.025
   T_tag (ms) = total_slots * bits_per_slot * 0.4
   T_overhead (ms) = (total_frames - 1) * 30

第一步：交叉（Crossover）- 融合父代基因
请分析父代 A 和父代 B 的 Python 代码，从它们的帧结构、响应规则、估计逻辑、终止条件和验证数据中提取可复用设计，生成结构完整且逻辑自洽的初始子代协议。

3. 增加早停、异常桶重检或置信度修正；
4. 增加面向多维统计任务的参数化算子，使同一协议骨架可服务不同统计目标。

class test_g2_3(IProtocol):
    def _get_tag_attr_value(self, tag: Tag) -> Any:
        return tag.__dict__.get("price")

    def _leading_zero_count(self, value: int, bit_len: int) -> int:
        if bit_len <= 0:
            return 0
        count = 0
        for i in range(bit_len - 1, -1, -1):
            if ((value >> i) & 1) == 0:
                count += 1
            else:
                break
        return count

    def _estimate_count_from_zero_bitmap(self, zero_count: int, frame_size: int) -> float:
        if frame_size <= 0:
            return 0.0
        if zero_count >= frame_size:
            return 0.0
        if zero_count <= 0:
            return float(frame_size) * 3.0
        ratio = zero_count / float(frame_size)
        return -frame_size * math.log(ratio)

    def _estimate_count_from_slot_bits(self, slot_bits: List[int], frame_size: int) -> float:
        occupied = sum(slot_bits)
        zeros = frame_size - occupied
        return self._estimate_count_from_zero_bitmap(zeros, frame_size)

    def _estimate_count_from_sog_or(self, combined_signal: int, bits_per_slot: int, omega: float = 1.2897) -> float:
        if bits_per_slot <= 0:
            return 0.0
        lz = self._leading_zero_count(combined_signal, bits_per_slot)
        return omega * (2 ** lz)

    def _adaptive_frame_size(self, candidate_count: int, stage: str) -> int:
        candidate_count = max(1, candidate_count)
        if stage == "coarse":
            return min(32768, max(256, min(4096, candidate_count * 8)))
        if stage == "refine":
            return min(32768, max(512, min(8192, candidate_count * 24)))
        if stage == "accurate":
            return min(32768, max(1024, min(16384, candidate_count * 128)))
        return min(32768, max(256, candidate_count * 8))

    def _tag_response_sem_batch(self, tag: Tag, batch_price_set: set, price_to_bit_pos: Dict[int, int], seed: int, frame_size: int):
        v = self._get_tag_attr_value(tag)
        if v in batch_price_set:
            slot_id = simple_hash(tag.id, seed) % frame_size
            bit_pos = price_to_bit_pos[v]
            return slot_id, (1 << bit_pos)
        return None

    def _tag_response_sog(self, tag: Tag, seed: int, frame_size: int, bits_per_slot: int):
        v = self._get_tag_attr_value(tag)
        if v is None:
            return None
        rnd = simple_hash(tag.id, seed)
        mu = 0
        found_one = False
        for i in range(bits_per_slot - 1, -1, -1):
            if (rnd >> i) & 1:
                found_one = True
                break
            mu += 1
        if not found_one:
            mu = bits_per_slot
        max_mask_bit = bits_per_slot - 1
        sog = 0 if mu >= bits_per_slot else (1 << (max_mask_bit - mu))
        slot_id = simple_hash(v, seed) % frame_size
        return slot_id, sog

    def _tag_response_single(self, tag: Tag, target_value: int, seed: int, frame_size: int):
        v = self._get_tag_attr_value(tag)
        if v == target_value:
            slot_id = simple_hash(tag.id, seed) % frame_size
            return slot_id, 1
        return None

    def _simulate_sem_batch_frame(self, tags: List[Tag], batch: List[int], frame_size: int, seed: int):
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=len(batch))
        price_to_bit_pos = {p: i for i, p in enumerate(batch)}
        batch_set = set(batch)
        for tag in tags:
            resp = self._tag_response_sem_batch(tag, batch_set, price_to_bit_pos, seed, frame_size)
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame, price_to_bit_pos

    def _simulate_sog_frame(self, tags: List[Tag], seed: int, frame_size: int, bits_per_slot: int):
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=bits_per_slot)
        for tag in tags:
            resp = self._tag_response_sog(tag, seed, frame_size, bits_per_slot)
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _simulate_single_value_frame(self, tags: List[Tag], target_value: int, frame_size: int, seed: int):
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=1)
        for tag in tags:
            resp = self._tag_response_single(tag, target_value, seed, frame_size)
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _run_parallel_sem_phase(
        self,
        tags: List[Tag],
        target_values: List[int],
        frame_size: int,
        batch_size: int,
        value_bit_len: int
    ) -> Tuple[Dict[int, float], Dict[int, int], Dict[str, int]]:
        estimated_counts: Dict[int, float] = {}
        saturation_flags: Dict[int, int] = {}
        frames_used = 0
        reader_bits = 0
        total_slots = 0

        batches = [target_values[i:i + batch_size] for i in range(0, len(target_values), batch_size)]
        for batch in batches:
            if not batch:
                continue
            seed = generate_random_seed()
            frames_used += 1
            reader_bits += seed.bit_length() + frame_size.bit_length() + len(batch).bit_length() + len(batch) * max(1, value_bit_len)
            total_slots += frame_size

            frame, price_to_bit_pos = self._simulate_sem_batch_frame(tags, batch, frame_size, seed)
            for value, bit_pos in price_to_bit_pos.items():
                logical_bits = [((slot_data >> bit_pos) & 1) for slot_data in frame.slots]
                zeros = frame_size - sum(logical_bits)
                saturation_flags[value] = 1 if zeros == 0 else 0
                estimated_counts[value] = self._estimate_count_from_slot_bits(logical_bits, frame_size)

        metrics = {
            "frames_used": frames_used,
            "reader_bits": reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": min(256, max(1, batch_size)),
        }
        return estimated_counts, saturation_flags, metrics

    def _run_sog_refine_phase(
        self,
        tags: List[Tag],
        candidate_values: List[int],
        frame_size: int,
        bits_per_slot: int,
        rounds: int
    ) -> Tuple[Dict[int, float], Dict[int, Dict[str, int]], Dict[str, int], List[int]]:
        stats = {v: {"sum_est": 0.0, "rounds": 0, "unique_hits": 0} for v in candidate_values}
        frames_used = 0
        reader_bits = 0
        total_slots = 0
        unique_counts_per_round: List[int] = []

        for _ in range(rounds):
            seed = generate_random_seed()
            frames_used += 1
            reader_bits += seed.bit_length() + frame_size.bit_length() + bits_per_slot.bit_length()
            total_slots += frame_size

            frame = self._simulate_sog_frame(tags, seed, frame_size, bits_per_slot)

            slot_to_candidates: Dict[int, List[int]] = {}
            for v in candidate_values:
                slot_id = simple_hash(v, seed) % frame_size
                slot_to_candidates.setdefault(slot_id, []).append(v)

            unique_hits_round = 0
            for slot_id, values in slot_to_candidates.items():
                if len(values) == 1:
                    unique_hits_round += 1
                    v = values[0]
                    est = self._estimate_count_from_sog_or(frame.slots[slot_id], bits_per_slot)
                    stats[v]["sum_est"] += est
                    stats[v]["rounds"] += 1
                    stats[v]["unique_hits"] += 1
            unique_counts_per_round.append(unique_hits_round)

        estimates: Dict[int, float] = {}
        for v in candidate_values:
            if stats[v]["rounds"] > 0:
                estimates[v] = stats[v]["sum_est"] / stats[v]["rounds"]
            else:
                estimates[v] = 0.0

        metrics = {
            "frames_used": frames_used,
            "reader_bits": reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": bits_per_slot,
        }
        return estimates, stats, metrics, unique_counts_per_round

    def _run_single_value_recheck(
        self,
        tags: List[Tag],
        target_value: int,
        frame_size: int
    ) -> Tuple[float, int, Dict[str, int]]:
        seed = generate_random_seed()
        reader_bits = seed.bit_length() + frame_size.bit_length() + max(1, abs(int(target_value))).bit_length()
        frame = self._simulate_single_value_frame(tags, target_value, frame_size, seed)
        occupied = frame_size - frame.slots.count(0)
        zeros = frame_size - occupied
        est = self._estimate_count_from_zero_bitmap(zeros, frame_size)
        metrics = {
            "frames_used": 1,
            "reader_bits": reader_bits,
            "total_slots": frame_size,
            "bits_per_slot": 1,
        }
        return est, occupied, metrics

    def _sort_scores_desc(self, d: Dict[int, float]):
        return sorted(d.items(), key=lambda kv: (-kv[1], kv[0]))

    def _select_conservative_modes(
        self,
        scores: Dict[int, float],
        max_candidates: int = 3,
        rel_threshold: float = 0.94
    ) -> List[int]:
        positive = [(k, v) for k, v in scores.items() if v is not None and v > 0]
        if not positive:
            return []
        positive.sort(key=lambda x: (-x[1], x[0]))
        top_score = positive[0][1]
        if top_score <= 0:
            return []
        selected = []
        for value, score in positive:
            if score >= top_score * rel_threshold:
                selected.append(value)
            if len(selected) >= max_candidates:
                break
        if not selected:
            selected = [positive[0][0]]
        return sorted(selected)

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        total_frames = 0
        total_bits_sent_by_reader = 0
        total_slots = 0

        all_values = list(range(price_min, price_max + 1))
        if not all_values:
            verification_data = {
                "frame_size": 0,
                "bits_per_slot": 0,
                "stage_frame_sizes": [],
                "stage_bits_per_slot": [],
                "total_frames": 0,
            }
            return [], 0, 0.0, verification_data

        value_bit_len = max(1, max(abs(price_min), abs(price_max), 1).bit_length() + 1)

        stage_frame_sizes: List[int] = []
        stage_bits_per_slot: List[int] = []
        stage_names: List[str] = []

        coarse_batch_size = min(128, max(16, len(all_values)))
        coarse_bits_per_slot = min(256, coarse_batch_size)
        coarse_frame_size = self._adaptive_frame_size(len(all_values), "coarse")

        # --- 交叉部分：融合父代 A 的分批位图并行估计与父代 B 的逐级候选筛选/自适应帧长思想 ---
        coarse_counts, coarse_saturation, coarse_metrics = self._run_parallel_sem_phase(
            tags=tags,
            target_values=all_values,
            frame_size=coarse_frame_size,
            batch_size=coarse_bits_per_slot,
            value_bit_len=value_bit_len
        )
        total_frames += coarse_metrics["frames_used"]
        total_bits_sent_by_reader += coarse_metrics["reader_bits"]
        total_slots += coarse_metrics["total_slots"]
        for _ in range(coarse_metrics["frames_used"]):
            stage_frame_sizes.append(coarse_frame_size)
            stage_bits_per_slot.append(coarse_bits_per_slot)
            stage_names.append("coarse_sem")

        sorted_coarse = self._sort_scores_desc(coarse_counts)
        candidate_pool_size = min(10, max(4, int(math.sqrt(max(1, len(all_values))))))
        coarse_candidates = [v for v, c in sorted_coarse[:candidate_pool_size] if c > 0]
        if not coarse_candidates and sorted_coarse:
            coarse_candidates = [sorted_coarse[0][0]]

        if not coarse_candidates:
            T_reader = total_bits_sent_by_reader * 0.025
            bits_for_time = max(1, int(sum(stage_bits_per_slot) / len(stage_bits_per_slot))) if stage_bits_per_slot else 1
            T_tag = total_slots * bits_for_time * 0.4
            T_overhead = (total_frames - 1) * 30 if total_frames > 1 else 0
            total_time_ms = T_reader + T_tag + T_overhead
            verification_data = {
                "frame_size": coarse_frame_size,
                "bits_per_slot": coarse_bits_per_slot,
                "stage_frame_sizes": stage_frame_sizes,
                "stage_bits_per_slot": stage_bits_per_slot,
                "stage_names": stage_names,
                "total_frames": total_frames,
                "coarse_counts": dict(sorted_coarse[:candidate_pool_size]),
                "coarse_saturation_flags": coarse_saturation,
                "early_stop": True,
            }
            return [], 0, total_time_ms, verification_data

        refine_frame_size = self._adaptive_frame_size(len(coarse_candidates), "refine")
        refine_bits_per_slot = 32
        refine_rounds = 4 if len(coarse_candidates) <= 8 else 5

        sog_estimates, sog_stats, sog_metrics, unique_counts_per_round = self._run_sog_refine_phase(
            tags=tags,
            candidate_values=coarse_candidates,
            frame_size=refine_frame_size,
            bits_per_slot=refine_bits_per_slot,
            rounds=refine_rounds
        )
        total_frames += sog_metrics["frames_used"]
        total_bits_sent_by_reader += sog_metrics["reader_bits"]
        total_slots += sog_metrics["total_slots"]
        for _ in range(sog_metrics["frames_used"]):
            stage_frame_sizes.append(refine_frame_size)
            stage_bits_per_slot.append(refine_bits_per_slot)
            stage_names.append("refine_sog")

        fusion_scores: Dict[int, float] = {}
        for v in coarse_candidates:
            coarse_score = coarse_counts.get(v, 0.0)
            sog_score = sog_estimates.get(v, 0.0)
            unique_hits = sog_stats.get(v, {}).get("unique_hits", 0)
            reliability = min(1.0, unique_hits / max(1.0, refine_rounds * 0.7))
            if sog_score > 0:
                fusion_scores[v] = (0.55 + 0.15 * reliability) * coarse_score + (0.45 - 0.15 * reliability) * sog_score
            else:
                fusion_scores[v] = 0.85 * coarse_score

        ranked_fusion = self._sort_scores_desc(fusion_scores)
        preliminary_final = [v for v, _ in ranked_fusion[:min(4, len(ranked_fusion))]]

        # --- 突变部分：引入“置信差驱动的候选重检 + 动态早停 + 多阶段校验”全新机制 ---
        need_recheck = False
        early_stop = False
        confidence_gap = 1.0
        if len(ranked_fusion) >= 2 and ranked_fusion[0][1] > 0:
            best = ranked_fusion[0][1]
            second = ranked_fusion[1][1]
            confidence_gap = (best - second) / max(best, 1e-9)
            if confidence_gap < 0.12:
                need_recheck = True
        else:
            early_stop = True

        final_counts: Dict[int, float] = {}
        occupied_map: Dict[int, int] = {}
        recheck_targets = preliminary_final[:]

        if need_recheck and recheck_targets:
            accurate_frame_size = self._adaptive_frame_size(len(recheck_targets), "accurate")
            for v in recheck_targets:
                est, occupied, metrics = self._run_single_value_recheck(tags, v, accurate_frame_size)
                total_frames += metrics["frames_used"]
                total_bits_sent_by_reader += metrics["reader_bits"]
                total_slots += metrics["total_slots"]
                stage_frame_sizes.append(accurate_frame_size)
                stage_bits_per_slot.append(1)
                stage_names.append("accurate_single")
                final_counts[v] = est
                occupied_map[v] = occupied

            for v in recheck_targets:
                fusion = fusion_scores.get(v, 0.0)
                recheck = final_counts.get(v, 0.0)
                final_counts[v] = 0.35 * fusion + 0.65 * recheck
        else:
            early_stop = True
            final_counts = dict(fusion_scores)
            accurate_frame_size = refine_frame_size

        estimated_values: List[int] = []
        metric = 0
        if final_counts:
            ordered_final = self._sort_scores_desc(final_counts)
            if len(ordered_final) >= 2 and ordered_final[0][1] > 0:
                best = ordered_final[0][1]
                second = ordered_final[1][1]
                final_gap = (best - second) / max(best, 1e-9)
                if final_gap < 0.06:
                    threshold = best * 0.94
                elif final_gap < 0.15:
                    threshold = best * 0.965
                else:
                    threshold = best * 0.992
            else:
                best = ordered_final[0][1]
                threshold = best * 0.992

            estimated_values = self._select_conservative_modes(
                final_counts,
                max_candidates=3,
                rel_threshold=min(0.995, max(0.92, threshold / max(best, 1e-9))) if best > 0 else 0.95

class test_g2_2(IProtocol):
    """
    面向离散属性众数/多众数查询的混合式 RFID 协议。
    设计目标：
    1) 继承批量位图并行估计基因；
    2) 继承逐级候选筛选与复核基因；
    3) 通过匿名聚合帧完成众数/多众数保守输出；
    4) 为后续扩展到多种统计任务保留协议骨架。
    """

    def _safe_attr_value(self, tag: Tag) -> Any:
        return tag.__dict__.get("price")

    def _leading_zero_index(self, value: int, width: int) -> int:
        for i in range(width):
            bit = (value >> (width - 1 - i)) & 1
            if bit == 1:
                return i
        return width

    def _build_sog_bit(self, tag_id: Any, seed: int, sog_length: int) -> int:
        rnd = simple_hash(tag_id, seed)
        idx = self._leading_zero_index(rnd, sog_length)
        if idx >= sog_length:
            return 0
        return 1 << (sog_length - 1 - idx)

    def _tag_response_bitmap(
        self,
        tag: Tag,
        target_set: set,
        value_to_bit: Dict[int, int],
        seed: int,
        frame_size: int
    ):
        v = self._safe_attr_value(tag)
        if v not in target_set:
            return None
        slot_id = simple_hash(tag.id, seed) % frame_size
        return slot_id, (1 << value_to_bit[v])

    def _tag_response_sog(
        self,
        tag: Tag,
        target_set: set,
        value_to_bit: Dict[int, int],
        seed: int,
        frame_size: int,
        sog_seed_base: int,
        sog_length: int
    ):
        v = self._safe_attr_value(tag)
        if v not in target_set:
            return None
        slot_seed = simple_hash(seed, v ^ 0x9E3779B1)
        slot_id = simple_hash(tag.id, slot_seed) % frame_size
        bit_pos = value_to_bit[v]
        sog_seed = simple_hash(sog_seed_base, v)
        sog_marker = self._build_sog_bit(tag.id, sog_seed, sog_length)
        strength = 1 if sog_marker != 0 else 0
        return slot_id, (strength << bit_pos)

    def _simulate_batch_frame(
        self,
        tags: List[Tag],
        batch: List[int],
        frame_size: int,
        seed: int,
        use_sog: bool = False,
        sog_length: int = 16
    ) -> Frame:
        bits_per_slot = max(1, len(batch))
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=bits_per_slot)
        value_to_bit = {v: i for i, v in enumerate(batch)}
        target_set = set(batch)
        sog_seed_base = simple_hash(seed, 0xA5A5A5A5)

        for tag in tags:
            if use_sog:
                resp = self._tag_response_sog(
                    tag, target_set, value_to_bit, seed, frame_size, sog_seed_base, sog_length
                )
            else:
                resp = self._tag_response_bitmap(
                    tag, target_set, value_to_bit, seed, frame_size
                )
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _simulate_single_value_frame(
        self,
        tags: List[Tag],
        target_value: int,
        frame_size: int,
        seed: int
    ) -> Frame:
        physical_frame = Frame(num_slots=frame_size, bits_per_slot=1)
        target_set = {target_value}
        value_to_bit = {target_value: 0}
        for tag in tags:
            resp = self._tag_response_bitmap(tag, target_set, value_to_bit, seed, frame_size)
            if resp is not None:
                slot_id, reply_vector = resp
                physical_frame.aggregate(slot_id, reply_vector)
        return physical_frame

    def _estimate_cardinality(self, logical_bits: List[int], frame_size: int) -> float:
        occupied = sum(logical_bits)
        zeros = frame_size - occupied
        if zeros == frame_size:
            return 0.0
        if zeros == 0:
            return float(frame_size) * 2.0
        return -frame_size * math.log(zeros / frame_size)

    def _estimate_with_correction(
        self,
        logical_bits: List[int],
        frame_size: int,
        use_sog: bool = False
    ) -> Tuple[float, Dict[str, float]]:
        occupied = sum(logical_bits)
        zeros = frame_size - occupied
        raw = self._estimate_cardinality(logical_bits, frame_size)
        occupancy_ratio = occupied / frame_size if frame_size > 0 else 0.0
        if use_sog:
            correction = 1.0 + 0.12 * occupancy_ratio
        else:
            correction = 1.0
        return raw * correction, {
            "occupied": float(occupied),
            "zeros": float(zeros),
            "occupancy_ratio": float(occupancy_ratio),
            "correction": float(correction),
        }

    def _adaptive_frame_size(self, candidate_count: int, stage: str) -> int:
        candidate_count = max(1, candidate_count)
        if stage == "coarse":
            base = max(64, min(2048, candidate_count * 4))
        elif stage == "refine":
            base = max(256, min(8192, candidate_count * 32))
        else:
            base = max(512, min(16384, candidate_count * 96))
        power = 1
        while power < base and power < 32768:
            power <<= 1
        return min(32768, max(64, power))

    def _chunk_values(self, values: List[int], batch_size: int) -> List[List[int]]:
        return [values[i:i + batch_size] for i in range(0, len(values), batch_size)]

    def _run_parallel_stage(
        self,
        tags: List[Tag],
        target_values: List[int],
        frame_size: int,
        batch_size: int,
        rounds: int,
        use_sog: bool,
        sog_length: int
    ) -> Tuple[Dict[int, float], Dict[int, Dict[str, float]], Dict[str, int]]:
        aggregated: Dict[int, float] = {}
        seen: Dict[int, int] = {}
        diagnostics: Dict[int, Dict[str, float]] = {}
        total_frames = 0
        total_reader_bits = 0
        total_slots = 0
        bits_per_slot = max(1, min(batch_size, 256))

        batches = self._chunk_values(target_values, batch_size)

        for _ in range(rounds):
            for batch in batches:
                if not batch:
                    continue
                seed = generate_random_seed()
                total_frames += 1
                total_reader_bits += seed.bit_length() + frame_size.bit_length() + len(batch).bit_length() + max(1, sog_length.bit_length())
                total_slots += frame_size

                physical_frame = self._simulate_batch_frame(
                    tags=tags,
                    batch=batch,
                    frame_size=frame_size,
                    seed=seed,
                    use_sog=use_sog,
                    sog_length=sog_length
                )

                for bit_pos, value in enumerate(batch):
                    logical_bits = [((slot_data >> bit_pos) & 1) for slot_data in physical_frame.slots]
                    est, info = self._estimate_with_correction(logical_bits, frame_size, use_sog=use_sog)
                    aggregated[value] = aggregated.get(value, 0.0) + est
                    seen[value] = seen.get(value, 0) + 1
                    prev = diagnostics.get(value, {"occupied": 0.0, "zeros": 0.0, "occupancy_ratio": 0.0, "correction": 0.0})
                    diagnostics[value] = {
                        "occupied": prev["occupied"] + info["occupied"],
                        "zeros": prev["zeros"] + info["zeros"],
                        "occupancy_ratio": prev["occupancy_ratio"] + info["occupancy_ratio"],
                        "correction": prev["correction"] + info["correction"],
                    }

        final_counts: Dict[int, float] = {}
        for v in target_values:
            cnt = seen.get(v, 0)
            if cnt <= 0:
                final_counts[v] = 0.0
                continue
            final_counts[v] = aggregated[v] / cnt
            d = diagnostics.get(v)
            if d is not None:
                diagnostics[v] = {
                    "occupied": d["occupied"] / cnt,
                    "zeros": d["zeros"] / cnt,
                    "occupancy_ratio": d["occupancy_ratio"] / cnt,
                    "correction": d["correction"] / cnt,
                }

        metrics = {
            "frames_used": total_frames,
            "reader_bits": total_reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": bits_per_slot,
        }
        return final_counts, diagnostics, metrics

    def _run_single_verify_stage(
        self,
        tags: List[Tag],
        candidate_values: List[int],
        frame_size: int,
        rounds: int
    ) -> Tuple[Dict[int, float], Dict[int, int], Dict[str, int]]:
        estimates: Dict[int, float] = {}
        occupied_map: Dict[int, int] = {}
        total_frames = 0
        total_reader_bits = 0
        total_slots = 0

        for value in candidate_values:
            est_acc = 0.0
            occ_acc = 0
            used = 0
            for _ in range(rounds):
                seed = generate_random_seed()
                total_frames += 1
                total_reader_bits += seed.bit_length() + frame_size.bit_length() + max(1, int(value)).bit_length() if isinstance(value, int) and value > 0 else seed.bit_length() + frame_size.bit_length() + 1
                total_slots += frame_size
                physical_frame = self._simulate_single_value_frame(tags, value, frame_size, seed)
                logical_bits = [1 if slot_data != 0 else 0 for slot_data in physical_frame.slots]
                est = self._estimate_cardinality(logical_bits, frame_size)
                est_acc += est
                occ_acc += sum(logical_bits)
                used += 1
            estimates[value] = est_acc / max(1, used)
            occupied_map[value] = int(round(occ_acc / max(1, used)))

        metrics = {
            "frames_used": total_frames,
            "reader_bits": total_reader_bits,
            "total_slots": total_slots,
            "bits_per_slot": 1,
        }
        return estimates, occupied_map, metrics

    def _sort_desc(self, d: Dict[int, float]) -> List[Tuple[int, float]]:
        return sorted(d.items(), key=lambda kv: (-kv[1], kv[0]))

    def _select_top_with_ties(self, estimates: Dict[int, float], limit: int) -> List[int]:
        ordered = self._sort_desc(estimates)
        if not ordered:
            return []
        if len(ordered) <= limit:
            return [v for v, _ in ordered]
        threshold = ordered[limit - 1][1]
        selected = [v for v, s in ordered if s >= threshold]
        return selected[:max(limit + 2, limit)]

    def _confidence_interval_radius(self, est: float, frame_size: int, rounds: int) -> float:
        if est <= 0:
            return 0.5
        variance_proxy = max(1.0, est)
        radius = 1.2 * math.sqrt(variance_proxy / max(1, rounds))
        density_penalty = 0.02 * frame_size / max(64, frame_size)
        return radius + density_penalty

    def _conservative_multimode_decision(
        self,
        refined_counts: Dict[int, float],
        verify_counts: Dict[int, float],
        verify_frame_size: int,
        verify_rounds: int
    ) -> Tuple[List[int], float, Dict[str, Any]]:
        if not verify_counts:
            ordered_ref = self._sort_desc(refined_counts)
            if not ordered_ref:
                return [], 0.0, {"decision": "empty"}
            return [ordered_ref[0][0]], ordered_ref[0][1], {"decision": "refine_fallback"}

        ordered = self._sort_desc(verify_counts)
        best_value, best_score = ordered[0]
        best_radius = self._confidence_interval_radius(best_score, verify_frame_size, verify_rounds)
        selected = [best_value]

        # --- 交叉部分：融合父代 A 的“多轮并行统计估计/SOG 校正”思想与父代 B 的“逐级候选筛选/单值复核”思想 ---
        # --- 突变部分：引入“置信区间修正 + 异常候选重检触发 + 早停”全新机制 ---
        abnormal_gap_trigger = False
        for value, score in ordered[1:]:
            radius = self._confidence_interval_radius(score, verify_frame_size, verify_rounds)
            refined_score = refined_counts.get(value, 0.0)
            refined_best = refined_counts.get(best_value, best_score)
            overlap = (best_score - best_radius) <= (score + radius)
            refined_close = abs(refined_best - refined_score) <= max(best_radius + radius, 0.08 * max(best_score, 1.0))
            if overlap and refined_close:
                selected.append(value)
            else:
                if best_score > 0 and (best_score - score) / best_score < 0.06:
                    abnormal_gap_trigger = True
                break

        selected = sorted(selected[:3])

        decision_info = {
            "decision": "verified",
            "best_score": best_score,
            "best_radius": best_radius,
            "abnormal_gap_trigger": abnormal_gap_trigger,
            "ordered_verify_top": ordered[:5],
        }
        return selected, best_score, decision_info
