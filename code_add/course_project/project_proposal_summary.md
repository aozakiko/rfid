# 项目申报书要点整理

## 项目名称

面向多维统计场景的 RFID 协议自优化 Web 平台开发

## 平台定位

构建一个面向 RFID/物联网统计任务的协议自优化平台，把协议设计从人工推导和离散脚本升级为可交互、可生成、可验证、可迭代的平台化流程。平台核心不是单一“众数查询”演示，而是围绕多维统计任务形成协议生成与自动评估闭环。

## 核心问题

传统 RFID 协议研究多聚焦单一查询任务，尤其是离散值众数或库存盘点类任务。项目希望突破单一任务限制，扩展到多维统计场景，包括均值、方差、标准差、中位数、分位数、基数估计、缺失盘点等任务，并通过大模型辅助完成协议交叉、变异、修复和验证。

## 技术路线

1. 需求建模：通过自然语言或配置化输入描述业务场景、标签规模、统计目标和约束，形成 GRDL 风格的任务表达。
2. 父代协议基因库：整理已有 RFID 协议中的帧结构、碰撞利用、位图、草图估计、自适应帧长、早停策略、多阶段验证等可复用机制。
3. 大模型辅助演化：使用 LLM 进行协议交叉、变异和修复，生成可执行 Python 协议代码。
4. 在线仿真沙箱：对生成协议进行功能逻辑、物理约束、信息隔离和任务烟测验证。
5. 实验与图表：通过鲁棒性/敏感度实验、进化图、dashboard 和 outputs 产物支撑可行性展示。
6. 平台化交互：用 Web 方式完成场景管理、代码查看、Prompt 生成、协议生成、验证测试、自动迭代、产物预览和审计记录。

## 应用领域

智能制造、供应链管理、智慧医疗、工业传感监测、库存盘点、质量分布评估、标签群体状态估计等。

## 与当前课程项目的对应关系

当前实现以统一 Web 自优化平台为主体，保留已有 RFID 协议资产和实验脚本，并补充任务画像、模型接入、异步进度、协议生成、在线验证、自动迭代、资产分组、页面级说明书、outputs 预览和审计数据库，作为课程报告中“问题分析与解决能力”和“技术开发能力”的核心支撑。
