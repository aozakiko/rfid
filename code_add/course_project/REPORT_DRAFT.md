# 面向云边端协同部署的 RFID 协议自优化平台设计与实现

> 可将本文整理到学校统一课程报告模板中。

## 1. 选题背景

RFID 是物联网感知层的重要技术，广泛用于仓储、物流、零售、医疗资产和校园设备管理。传统 RFID 系统多关注身份识别和简单盘点，但在高动态物流、冷链监管、危化品仓储等场景中，系统还需要同时满足低延迟、高准确率、抗干扰、安全审计和云端追溯等要求。手工设计 RFID 查询协议依赖专家经验，难以在复杂约束下快速迭代。

本项目基于已有 RFID 协议演化代码，扩展实现一个“理论模型 - 自动生成 - 深度优化 - 场景验证 - 平台封装 - 云边端反馈”的自优化平台。系统允许普通用户用自然语言描述业务需求，平台自动生成 GRDL 形式化需求、AHP 协议匹配结果、LLM 优化 Prompt、部署 Manifest，并可直接运行云边端仿真流程。

## 2. 需求分析

目标用户包括物联网课程实验用户、RFID 协议研究者、智慧仓储/物流系统开发者和资产管理运维人员。系统需要完成以下功能：

1. 支持冷链、物流、零售、医疗、档案、制造、危化、校园资产等多种业务场景。
2. 支持自然语言需求建模，并可选择库存计数、丢失检测、未知标签检测、温湿度异常、Top-K 热点、路径追溯、抗碰撞、低功耗、安全审计等任务。
3. 支持云边端任务划分：端侧采集与签名，边缘侧协议推理和低延迟告警，云端流处理、批处理、审计和反馈优化。
4. 支持流处理和一般处理：云端滑动窗口实时统计，采集结束后生成全局报表。
5. 支持分布式计算和大模型技术：多边缘网关并发处理，LLM Prompt 用于协议交叉、变异和修复。
6. 支持网络安全和数据库审计：HMAC-SHA256 校验消息完整性，SQLite 保存运行、设备、告警、设计案例和 AI 任务。

非功能需求包括可运行、可解释、可测试、可展示和可迁移。项目应能在本地一键启动交互式平台，并生成课程报告可引用的 JSON、CSV、HTML 和 Markdown 结果。

## 3. 总体方案

系统采用云边端三层架构：

- 端侧：模拟 RFID 读写器和温湿度传感器，生成标签批次、环境数据，并对消息进行 HMAC 签名。
- 边缘侧：边缘网关校验签名，执行 RFID 查询协议，完成热点识别、缺失检测、温度异常告警和摘要压缩。
- 云端：接收边缘摘要，维护滑动窗口完成流处理，采集结束后进行批处理汇总，同时保存数据库审计记录，并将运行指标反馈给协议选择和调参模块。

平台核心为 `platform_core.py`：

- GRDL：把自然语言需求转化为集合 E/T/M/U、任务算子和约束。
- AHP：从结构、功能、约束、上下文、流程五个维度匹配已有协议。
- LLM Prompt：根据业务需求、GRDL、候选父代协议和云边端约束生成可直接用于协议生成的提示词。
- 优化策略：通信合并、参数调优、上下文感知切换、低功耗采样、云端反馈重排。
- 三重验证：功能仿真、物理层约束、信息隔离验证，并补充边缘部署和云端审计验证。

## 4. 关键实现

交互式平台由 `course_project/web_app.py` 和 `course_project/ui.py` 实现。用户可在浏览器中完成需求建模、图表分析、部署清单生成、运行验证和数据库审计。

云边端流水线由 `cloud_edge_demo/pipeline.py` 实现。`ShelfReaderDevice` 负责端侧采集，`EdgeGateway` 负责边缘处理，`CloudCoordinator` 负责云端流处理和批处理。系统使用 `ThreadPoolExecutor` 并发模拟多个边缘网关，体现分布式计算思想。

数据库由 `course_project/database.py` 实现，核心表包括 `runs`、`devices`、`gateways`、`stream_snapshots`、`gateway_summaries`、`alerts`、`security_checks`、`benchmark_results`、`ai_jobs`、`design_cases`、`deployment_manifests` 和 `system_events`。

安全模块由 `course_project/security.py` 实现，验证正常消息可通过，而篡改负载、错误密钥、缺失签名均会被拒绝。

## 5. 测试与结果

运行测试：

```powershell
python -m unittest course_project.test_course_project -v
```

测试覆盖：

- 云边端流程可完成端侧采集、边缘推理、云端流处理和批处理。
- HMAC 安全模块能拒绝篡改、错误密钥和缺失签名。
- SQLite 能保存运行记录、流窗口、网关汇总和告警。
- 自然语言需求能生成场景、任务、优先级、GRDL、Prompt、部署 Manifest 和图表数据。

启动交互式平台：

```powershell
python -m course_project.web_app --host 127.0.0.1 --port 8765
```

浏览器访问 `http://127.0.0.1:8765`，可生成设计案例并启动云边端运行。一次完整运行会在 `course_project/outputs/` 下生成场景配置、流处理 CSV、批处理 JSON、告警 CSV、基准实验 CSV、HTML 看板和运行摘要。

## 6. 独创性说明

本项目不是简单 RFID 仿真，而是把已有 RFID 协议演化研究扩展为可交互、可部署、可验证的云边端平台。创新点包括：

- 普通用户自然语言需求到 GRDL 和 Prompt 的自动转化。
- AHP 协议画像匹配与 LLM 协议生成联动。
- 通信合并、参数调优、上下文切换和低功耗采样的优化编排。
- 功能、物理层、信息隔离三重验证与数据库审计结合。
- 将流处理、批处理、分布式边缘计算和安全签名统一到课程项目中。

## 7. 社会价值

系统可应用于冷链食品和药品监管、智慧物流分拣、无人零售货架、医疗耗材管理、图书档案盘点、制造业在制品跟踪和校园资产管理。通过边缘计算降低云端压力，通过流处理提高告警实时性，通过数据库审计增强可追溯性，通过大模型辅助协议优化提高系统适应复杂场景的能力。

## 8. 总结与讨论

项目完成了一个符合课程要求的物联网云边端协同软件原型，支持传感层、网络层、应用层、任务划分、网络安全、云端处理、大数据/流批处理、分布式计算和大模型 Prompt 生成。后续可进一步接入真实 RFID 读写器、MQTT 消息中间件、时序数据库和在线 LLM API，将当前本地仿真平台迁移为真实部署系统。
