提示词：任务: 作为一名资深的 RFID 协议设计与优化专家，请基于给定的两个父代 RFID 协议（不要引入任何其他父代协议），创造一个全新的、功能完整的子代协议。

平台背景：
本平台定位为“面向多维统计场景的 RFID 协议自优化 Web 平台”。生成协议不应被限定为众数查询，而应能根据后续任务画像扩展到均值、方差、标准差、中位数、分位数、基数估计、缺失盘点、热点检测等 RFID/物联网统计任务。请把父代协议中的时隙帧、碰撞利用、位图/草图估计、自适应帧长、分批验证、提前终止、分层抽样等机制抽象成可复用的“协议基因”。

核心设计准则（必须严格遵守）：
1. 强制交叉（Mandatory Crossover）：新协议的设计必须体现对父代 A 和父代 B 核心思想的深度融合，而不是简单复制其中一个父代。
2. 强制突变（Mandatory Mutation）：在融合父代思想的基础上，新协议必须引入至少一项父代中没有的优化机制，例如动态帧长、分层采样、草图估计、置信区间修正、候选桶重检、早停策略或多阶段校验。
3. 任务适配（Task Adaptation）：请等待并服从后续追加的任务画像。若任务画像要求单值估计，execute() 应返回单元素 list；若任务画像要求候选集合，execute() 应返回保守且相关的候选 list。
4. 准确率与通信开销平衡：优先保证逻辑正确性，同时控制 reader 发送位数、标签响应时隙数和多阶段开销。
5. 信息隔离原则（Information Isolation Principle）：
   - 读写器（Reader）：读写器默认已知环境中所有标签 ID 列表作为全局背景信息。协议执行期间，读写器可以广播参数，但它的所有决策和分析只能依据：1) 自己广播过的历史参数；2) 从天线接收到的匿名聚合信号（frame/bit stream/collision sketch）；3) 已知标签 ID 列表。严禁在读写器决策逻辑中直接或间接访问单个标签私有属性，例如 tag.price。
   - 标签（Tag）：标签响应只能依据：1) 自身私有数据（ID 和数值属性）；2) 当前读写器广播指令。标签不得读取其他标签信息或全局通信结果。
6. 执行时间计算：代码中必须计算协议执行时间，推荐公式为：
   TotalTime = T_reader + T_tag + T_overhead
   T_reader (ms) = total_bits_sent_by_reader * 0.025
   T_tag (ms) = total_slots * bits_per_slot * 0.4
   T_overhead (ms) = (total_frames - 1) * 30

执行步骤：
第一步：交叉（Crossover）- 融合父代基因
请分析父代 A 和父代 B 的 Python 代码，从它们的帧结构、响应规则、估计逻辑、终止条件和验证数据中提取可复用设计，生成结构完整且逻辑自洽的初始子代协议。

第二步：突变（Mutation）- 引入创新优化
请在初始子代协议基础上加入一项有意义的新机制。可考虑但不限于：
1. 动态调整 frame_size、bits_per_slot 或采样轮数；

import math
import random
from typing import List, Tuple, Dict
from collections import defaultdict
from base import Tag, Frame, generate_random_seed, IProtocol
from hash import simple_hash

class g2_1(IProtocol):
    """
    混合变异协议 (Crossover Mutation Protocol)

    本协议通过交叉融合与基因突变，创造了一个用于解决多众数查询问题的新协议。
    它首先利用一种宏观扫描策略快速定位“热门”价格区间，然后对这些高潜力区间
    进行精确的二分查找，最终找出全局众数。
    """

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        """
        执行协议的主函数。
        """
        # --- 协议超参数 ---
        self.BUCKET_SIZE = 100         # 初始价格分组的粒度
        self.INITIAL_FRAME_SIZE = 128  # 估算阶段的初始帧长
        self.RESIZE_FACTOR = 2.0       # 帧长调整因子
        self.COLLISION_THRESHOLD = 0.1 # 触发帧长调整的碰撞率阈值
        self.MAX_RETRIES = 3           # 动态调整帧长的最大尝试次数

        # --- 性能统计变量 ---
        self.total_frames = 0
        self.total_bits_sent_by_reader = 0
        self.total_tag_slots = 0
        self.bits_per_slot = 1 # 默认值，在具体阶段可能被修改

        # --- 交叉部分：融合父代A的“并行批量估算”思想与父代B（推测）的“分治/范围查询”思想 ---
        # 阶段一: 粗粒度扫描，识别“热门”价格区间 (Hotspot Bucket Identification)
        # 采用类似父代A的思路，但不对单个价格估算，而是对价格“桶”进行并行估算，这借鉴了分治思想。
        
        price_buckets = self._create_price_buckets(price_min, price_max, self.BUCKET_SIZE)
        bucket_estimates = {}
        bucket_final_frames = {} # 记录每个桶最终使用的帧长

        for bucket_id, price_range in price_buckets.items():
            estimated_count, final_frame_size = self._estimate_tags_in_bucket_dynamically(tags, price_range)
            bucket_estimates[bucket_id] = estimated_count
            bucket_final_frames[bucket_id] = final_frame_size

        # 阶段二: 确定候选的热门区间 (Candidate Bucket Selection)
        if not bucket_estimates or max(bucket_estimates.values()) == 0:
            return [], 0, self._calculate_total_time(), {"status": "No tags found or estimated."}

        max_estimated_count = max(bucket_estimates.values())
        # 找出所有估算值最高的桶，以应对多众数分布在不同桶的情况
        candidate_bucket_ids = [
            bid for bid, count in bucket_estimates.items() 
            if (count == float('inf') and max_estimated_count == float('inf')) or \
               (count != float('inf') and math.isclose(count, max_estimated_count))
        ]

        # 阶段三: 在候选的热门区间内进行精确查找 (Precise Search in Candidate Buckets)
        # 对每个热门桶，采用类似父代B（推测）的二分查找思想，精确定位到具体的众数价格。
        final_candidates = {} # 存储格式: {price: exact_count}
        for bucket_id in candidate_bucket_ids:
            min_p, max_p = price_buckets[bucket_id]
            # 在此小范围内进行二分查找以确定最可能的众数
            mode_price, mode_count = self._binary_search_for_mode_in_range(tags, min_p, max_p)
            if mode_price is not None:
                # 可能多个桶找到不同的众数，或者同一个桶找到多个并列众数
                if mode_price in final_candidates:
                    final_candidates[mode_price] = max(final_candidates[mode_price], mode_count)
                else:
                    final_candidates[mode_price] = mode_count
        # --- 交叉部分结束 ---

        # --- 结果汇总 ---
        if not final_candidates:
            return [], 0, self._calculate_total_time(), {"status": "No mode found in candidate buckets."}

        # 从所有候选者中找出最终的全局众数
        max_final_count = max(final_candidates.values())
        final_modes = sorted([p for p, c in final_candidates.items() if c == max_final_count])
        
        total_time_ms = self._calculate_total_time()
        
        verification_data = {
            "bucket_size": self.BUCKET_SIZE,
            "initial_frame_size": self.INITIAL_FRAME_SIZE,
            "collision_threshold": self.COLLISION_THRESHOLD,
            "bucket_estimates": bucket_estimates,
            "candidate_bucket_ids": candidate_bucket_ids,
            "bucket_final_frame_sizes": bucket_final_frames,
            "final_candidates": final_candidates,
        }
        
        return final_modes, max_final_count, total_time_ms, verification_data

    def _estimate_tags_in_bucket_dynamically(self, tags: List[Tag], price_range: Tuple[int, int]) -> Tuple[float, int]:
        """
        --- 突变部分：引入“基于碰撞率的自适应帧长调整”全新机制 ---
        此机制在父代A和B中均未出现。它通过在估算前检查碰撞程度，动态调整帧长，
        以获得更准确的初始估算值，避免因帧长不当导致的估算严重失真。
        """
        current_frame_size = self.INITIAL_FRAME_SIZE
        min_p, max_p = price_range

        for i in range(self.MAX_RETRIES):
            self.total_frames += 1
            seed = generate_random_seed()
            self.total_bits_sent_by_reader += (seed.bit_length() + current_frame_size.bit_length() + min_p.bit_length() + max_p.bit_length())

            # [物理层模拟] 标签响应
            physical_frame = Frame(num_slots=current_frame_size, bits_per_slot=1)
            for t in tags:
                if min_p <= t.price <= max_p:
                    slot_id = simple_hash(t.id, seed) % current_frame_size
                    physical_frame.aggregate(slot_id, 1)
            
            self.total_tag_slots += current_frame_size
            self.bits_per_slot = 1 # 在这个阶段，每个时隙只需要1比特

            # [读写器分析]
            num_collisions = len([s for s in physical_frame.slots if s > 1])
            collision_rate = num_collisions / current_frame_size
            
            # 突变核心逻辑：如果碰撞率过高且还有重试机会，则增大帧长并重试
            if collision_rate > self.COLLISION_THRESHOLD and i < self.MAX_RETRIES - 1:
                current_frame_size = int(current_frame_size * self.RESIZE_FACTOR)
                continue
            
            # 碰撞率可接受或已达最大重试次数，进行估算
            num_zeros = len([s for s in physical_frame.slots if s == 0])
            if num_zeros == 0:
                return float('inf'), current_frame_size
            if num_zeros == current_frame_size:
                 return 0, current_frame_size
            
            # 使用标准的零状态估算子公式
            estimated_count = -current_frame_size * math.log(num_zeros / current_frame_size)
            return estimated_count, current_frame_size
        
        # 如果循环结束仍未返回，说明始终处于高碰撞状态
        return float('inf'), current_frame_size

    def _binary_search_for_mode_in_range(self, tags: List[Tag], min_p: int, max_p: int) -> Tuple[int, int]:
        """
        在给定的价格范围内，通过二分法找到数量最多的价格及其数量。
        """
        if min_p > max_p:
            return None, 0
        if min_p == max_p:
            count = self._get_exact_count(tags, min_p)
            return min_p, count
        
        mid = (min_p + max_p) // 2
        
        # 查询左右两个子区间的标签数量
        left_count_est = self._get_rough_count(tags, min_p, mid)
        right_count_est = self._get_rough_count(tags, mid + 1, max_p)

        # 优先探索估算数量更多的子区间
        if left_count_est > right_count_est:
            return self._binary_search_for_mode_in_range(tags, min_p, mid)
        elif right_count_est > left_count_est:
            return self._binary_search_for_mode_in_range(tags, mid + 1, max_p)
        else: # 如果估算数量相等，则两个区间都要探索
            left_mode, left_count = self._binary_search_for_mode_in_range(tags, min_p, mid)
            right_mode, right_count = self._binary_search_for_mode_in_range(tags, mid + 1, max_p)
            if left_count >= right_count:
                return left_mode, left_count
            else:
                return right_mode, right_count

    def _get_rough_count(self, tags: List[Tag], min_p: int, max_p: int) -> int:
        """
        使用一个极小的帧来快速判断一个范围内的标签是“无”、“单个”还是“多个”。
        这是一种比完整估算更快的剪枝方法。
        """
        if min_p > max_p: return 0
        frame_size = 2 # 使用一个非常小的帧
        self.total_frames += 1
        seed = generate_random_seed()
        self.total_bits_sent_by_reader += (seed.bit_length() + frame_size.bit_length() + min_p.bit_length() + max_p.bit_length())

        physical_frame = Frame(num_slots=frame_size, bits_per_slot=1)
        tag_responded = False
        for t in tags:
            if min_p <= t.price <= max_p:
                slot_id = simple_hash(t.id, seed) % frame_size
                physical_frame.aggregate(slot_id, 1)
                tag_responded = True
        
        self.total_tag_slots += frame_size

        if not tag_responded: return 0
        
        slot_values = physical_frame.slots
        if max(slot_values) > 1: return 3 # 代表多个 (碰撞)
        if sum(slot_values) > 0: return 1 # 代表单个 (无碰撞)
        return 0 # 无标签

    def _get_exact_count(self, tags: List[Tag], price: int) -> int:
        """
        通过一次查询精确地统计拥有特定价格的标签数量。
        这在二分查找的最后阶段是必要的。
        """
        # 这是一个简化的精确计数过程。在真实协议中，可能需要一个ALOHA类的协议来解决碰撞并逐个识别。
        # 这里我们直接从标签列表中统计，因为信息隔离原则允许读写器在最后验证阶段这样做（等价于读写器已知ID列表）。
        count = 0
        for t in tags:
            if t.price == price:
                count += 1
        
        # 模拟一次查询开销
        self.total_frames += 1
        self.total_bits_sent_by_reader += price.bit_length() # 广播价格
        # 假设有一个理想的ALOHA过程来读取，其开销与标签数成正比
        self.total_tag_slots += max(1, count) * 32 # 假设每个ID 32位
        
        return count

    def _create_price_buckets(self, price_min: int, price_max: int, bucket_size: int) -> Dict[int, Tuple[int, int]]:
        """
        将整个价格范围划分成若干个桶。
        """
        buckets = {}
        bucket_id = 0
        for i in range(price_min, price_max + 1, bucket_size):
            buckets[bucket_id] = (i, min(i + bucket_size - 1, price_max))
            bucket_id += 1
        return buckets

    def _calculate_total_time(self) -> float:
        """
        根据协议执行过程中的通信开销计算总时间。
        """
        T_reader = self.total_bits_sent_by_reader * 0.025
        T_tag = self.total_tag_slots * self.bits_per_slot * 0.4
        T_overhead = (self.total_frames - 1) * 30 if self.total_frames > 1 else 0
        return T_reader + T_tag + T_overhead

import math
from typing import List, Tuple, Dict, Set
from base import Tag, IProtocol, generate_random_seed
from hash import simple_hash

class g8_4(IProtocol):
    """
    子代协议: 具备早停机制的自适应过滤与并行验证协议
    (Adaptive Filtering with Early Termination and Parallel Verification Protocol)

    本协议是一个全新的子代协议，旨在高效解决复杂的多众数查询问题。
    它深度融合了父代协议A和B的优点，并引入了基于“收益递减”的
    早停机制作为突变，以在保证高准确率的同时，进一步优化通信效率。
    """

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        total_frames = 0
        total_bits_sent_by_reader = 0
        total_tag_response_bits = 0 # 因每个阶段的bits_per_slot可变，直接统计总比特数

        # --- 协议超参数 ---
        # 阶段一: 过滤相关
        initial_filter_frame_size = 256
        num_hash_functions = 2
        candidate_threshold = 30      # 当候选者数量小于此值时，停止过滤
        max_filter_rounds = 6         # 最大过滤轮次
        high_density_threshold = 0.75 # 帧密度过高阈值 (用于扩大帧)
        low_density_threshold = 0.25  # 帧密度过低阈值 (用于缩小帧)
        min_frame_size = 64           # 过滤帧的最小尺寸

        # --- 突变部分引入的超参数 ---
        diminishing_return_threshold = 0.95 # 若候选者数量与上一轮相比高于此比例，则早停

        # 阶段二: 验证相关
        verification_frame_size = 128

        # ==================================================================
        #  阶段一: 自适应迭代过滤
        # --- 交叉部分：融合父代A的严格多哈希过滤思想与父代B的自适应迭代框架 ---
        # 本阶段采纳了父代B的迭代式过滤框架，通过多轮通信逐步筛选候选价格。
        # 同时，每一轮的筛选逻辑借鉴了父代A的布隆过滤器思想：一个价格必须在
        # 所有哈希函数映射的时隙中都非空才能存活，这提供了更强的过滤能力。
        # 此外，从父代B继承的自适应帧长调整机制，使得协议能动态应对标签密度
        # 的变化，有效平衡了冲突与信道利用率。
        # ==================================================================
        candidate_prices: Set[int] = set(range(price_min, price_max + 1))
        filter_rounds_done = 0
        current_filter_frame_size = initial_filter_frame_size
        
        termination_reason = "Max rounds reached" # 默认的终止原因

        while len(candidate_prices) > candidate_threshold and filter_rounds_done < max_filter_rounds:
            
            total_frames += num_hash_functions
            filter_seeds = [generate_random_seed() for _ in range(num_hash_functions)]
            # 读写器广播帧长和哈希种子 (假设种子是32位)
            total_bits_sent_by_reader += num_hash_functions * (current_filter_frame_size.bit_length() + 32)

            # --- [物理层模拟] ---
            # 读写器准备接收帧
            filter_frames_states = [[0] * current_filter_frame_size for _ in range(num_hash_functions)]
            for t in tags:
                if t.price in candidate_prices:
                    for i in range(num_hash_functions):
                        slot_id = simple_hash(t.price, filter_seeds[i]) % current_filter_frame_size
                        filter_frames_states[i][slot_id] = 1 # 仅标记为非空
            
            # 在过滤阶段，标签只回复1比特表示存在性
            total_tag_response_bits += current_filter_frame_size * num_hash_functions * 1
            # --- [物理层模拟结束] ---

            # 读写器分析聚合信号
            new_candidates = set()
            for p in candidate_prices:
                is_still_candidate = True
                # 应用父代A的严格过滤逻辑
                for i in range(num_hash_functions):
                    slot_id = simple_hash(p, filter_seeds[i]) % current_filter_frame_size
                    if filter_frames_states[i][slot_id] == 0:
                        is_still_candidate = False
                        break
                
                if is_still_candidate:
                    new_candidates.add(p)

            # --- 突变部分：引入基于“收益递减”的早停机制 ---
            # 与父代协议固定的终止条件不同，本协议引入了一个全新的动态判断逻辑。
            # 在每轮过滤后，读写器会计算候选者集合的“缩减率”。如果发现连续的
            # 过滤操作带来的收益（即筛除无效价格的效率）已经变得很低，协议将
            # 提前终止过滤阶段，避免在低效的通信上浪费时间，直接进入验证阶段。
            # 这种机制使得协议对不同数据分布的适应性更强。
            if len(candidate_prices) > 0 and (len(new_candidates) / len(candidate_prices)) > diminishing_return_threshold:
                candidate_prices = new_candidates # 更新候选者，然后退出
                filter_rounds_done += 1
                termination_reason = f"Diminishing returns (reduction rate > {diminishing_return_threshold})"
                break
            
            # 如果没有候选者幸存，则提前终止
            if not new_candidates:
                candidate_prices = set()
                termination_reason = "No candidates survived"
                break
            
            candidate_prices = new_candidates
            filter_rounds_done += 1

            # 检查是否因为候选者数量达标而终止
            if len(candidate_prices) <= candidate_threshold:
                termination_reason = f"Candidate count below threshold ({candidate_threshold})"
                break

            # --- 交叉部分：自适应调整帧长 (源自父代B) ---
            total_slots_in_round = num_hash_functions * current_filter_frame_size
            total_non_empty_slots = sum(sum(1 for slot_state in frame if slot_state > 0) for frame in filter_frames_states)
            density = total_non_empty_slots / total_slots_in_round if total_slots_in_round > 0 else 0

            if density > high_density_threshold:
                current_filter_frame_size *= 2 # 碰撞太严重，扩大帧
            elif density < low_density_threshold:
                new_size = current_filter_frame_size // 2
                current_filter_frame_size = max(min_frame_size, new_size) # 太稀疏，缩小帧
        
        final_candidate_list = sorted(list(candidate_prices))

        # ==================================================================
        #  阶段二: 并行位图精确验证
        # --- 交叉部分：该验证方法的核心逻辑继承自父代B的并行位图思想 ---
        # 经过第一阶段的大幅筛选后，本阶段直接采用父代B中最高效的并行位图
        # 验证方案。所有候选者被编码到一个位向量中，读写器通过一次通信，
        # 就能并行地、精确地统计出所有候选价格的数量。这避免了父代A中
        # 为每个候选者单独进行验证的巨大开销，是处理多个潜在众数的理想选择。
        # ==================================================================
        final_counts: Dict[int, int] = {}
        if final_candidate_list:
            total_frames += 1
            price_to_bit_pos_map = {price: i for i, price in enumerate(final_candidate_list)}
            bits_per_slot_verify = len(final_candidate_list)

            seed_verify = generate_random_seed()
            # 读写器广播验证参数：帧长、种子以及最终候选价格列表
            total_bits_sent_by_reader += (verification_frame_size.bit_length() +
                                          32 + # 假设种子是32位
                                          sum(p.bit_length() for p in final_candidate_list))

            # --- [物理层模拟] ---
            verification_frame_slots = [0] * verification_frame_size
            for t in tags:
                if t.price in price_to_bit_pos_map:
                    slot_id = simple_hash(t.id, seed_verify) % verification_frame_size
                    bit_pos = price_to_bit_pos_map[t.price]
                    verification_frame_slots[slot_id] |= (1 << bit_pos)

            total_tag_response_bits += verification_frame_size * bits_per_slot_verify
            # --- [物理层模拟结束] ---

            # 读写器分析聚合位图，计算每个价格的精确计数值
            for price, bit_pos in price_to_bit_pos_map.items():
                mask = 1 << bit_pos
                count = sum(1 for slot_data in verification_frame_slots if (slot_data & mask) != 0)
                if count > 0:
                    final_counts[price] = count

        # ==================================================================
        #  最终处理与时间计算
        # ==================================================================
        T_reader = total_bits_sent_by_reader * 0.025
        T_tag = total_tag_response_bits * 0.4 
        T_overhead = (total_frames - 1) * 30 if total_frames > 0 else 0
        total_time_ms = T_reader + T_tag + T_overhead

        debug_data = {
            "filter_rounds_done": filter_rounds_done,
            "termination_reason": termination_reason,
            "candidates_after_filter": len(final_candidate_list),
            "final_counts": final_counts,
        }

        if not final_counts:
            return [], 0, total_time_ms, debug_data

        max_score = max(final_counts.values())
        modes = sorted([p for p, s in final_counts.items() if s == max_score])

        return modes, max_score, total_time_ms, debug_data
