平台背景：
本平台定位为“面向多维统计场景的 RFID 协议自优化 Web 平台”。生成协议不应被限定为众数查询，而应能根据后续任务画像扩展到均值、方差、标准差、中位数、分位数、基数估计、缺失盘点、热点检测等 RFID/物联网统计任务。请把父代协议中的时隙帧、碰撞利用、位图/草图估计、自适应帧长、分批验证、提前终止、分层抽样等机制抽象成可复用的“协议基因”。

核心设计准则（必须严格遵守）：
1. 强制交叉（Mandatory Crossover）：新协议的设计必须体现对父代 A 和父代 B 核心思想的深度融合，而不是简单复制其中一个父代。
2. 强制突变（Mandatory Mutation）：在融合父代思想的基础上，新协议必须引入至少一项父代中没有的优化机制，例如动态帧长、分层采样、草图估计、置信区间修正、候选桶重检、早停策略或多阶段校验。

5. 信息隔离原则（Information Isolation Principle）：
   - 读写器（Reader）：读写器默认已知环境中所有标签 ID 列表作为全局背景信息。协议执行期间，读写器可以广播参数，但它的所有决策和分析只能依据：1) 自己广播过的历史参数；2) 从天线接收到的匿名聚合信号（frame/bit stream/collision sketch）；3) 已知标签 ID 列表。严禁在读写器决策逻辑中直接或间接访问单个标签私有属性，例如 tag.price。

6. 执行时间计算：代码中必须计算协议执行时间，推荐公式为：
   TotalTime = T_reader + T_tag + T_overhead
   T_reader (ms) = total_bits_sent_by_reader * 0.025
   T_tag (ms) = total_slots * bits_per_slot * 0.4
   T_overhead (ms) = (total_frames - 1) * 30

class g2_2(IProtocol):
    """
    自适应混合选择估算协议 (Adaptive Hybrid Selective Estimation Protocol)

    本协议是一个全新的子代协议，旨在解决多众数查询问题。
    它深度融合了父代协议的设计思想，并引入了创新的优化机制。

    协议流程分为三个阶段：
    1.  **粗估筛选阶段 (Crossover)**: 融合父代A的并行批量估算思想，使用较小的帧快速扫描
        整个价格范围，以低成本识别出潜在的候选价格集。这体现了父代A的效率。
    2.  **精估排序阶段 (Crossover)**: 融合了推断的父代B的“过滤”和“聚焦”思想。对上一阶段
        筛选出的少数候选价格，使用更大的帧进行更精确的数量估算，从而进一步缩小范围，
        锁定最有可能成为众数的几个价格。
    3.  **精确计数阶段 (Mutation)**: 引入了全新的“单价精确计数”机制。对极少数最终候选者，
        协议不再使用概率估算，而是为每个候选价格发起一次独立的、高精度的计数查询，
        从而获得近乎确定的计数值，确保在计数值相近时也能做出最准确的判决。
    """

    def _run_estimation_phase(
        self,
        tags: List[Tag],
        target_prices: List[int],
        frame_size: int,
        batch_size: int
    ) -> Tuple[Dict[int, float], int, int, int]:
        """
        一个通用的估算阶段执行函数。
        
        Args:
            tags: 所有标签的列表。
            target_prices: 此阶段需要估算数量的价格列表。
            frame_size: 用于估算的帧大小。
            batch_size: 每个通信帧并行处理的价格数量。

        Returns:
            一个元组，包含：
            - estimated_counts: 估算出的每个价格的数量。
            - frames_used: 此阶段使用的总帧数。
            - reader_bits: 读写器在此阶段发送的总比特数。
            - tag_bits: 标签在此阶段发送的总比特数。
        """
        estimated_counts = {}
        frames_used = 0
        reader_bits = 0
        tag_bits = 0

        price_batches = [target_prices[i:i + batch_size] for i in range(0, len(target_prices), batch_size)]

        for batch in price_batches:
            if not batch:
                continue

            frames_used += 1
            num_prices_in_batch = len(batch)
            seed = generate_random_seed()
            price_to_bit_pos_map = {price: i for i, price in enumerate(batch)}

            # 读写器广播参数
            reader_bits += (seed.bit_length() + frame_size.bit_length() + num_prices_in_batch.bit_length())

            # [物理层模拟]
            physical_frame = Frame(num_slots=frame_size, bits_per_slot=num_prices_in_batch)
            batch_price_set = set(batch)
            for t in tags:
                if t.price in batch_price_set:
                    slot_id = simple_hash(t.id, seed) % frame_size
                    bit_pos = price_to_bit_pos_map[t.price]
                    reply_vector = 1 << bit_pos
                    physical_frame.aggregate(slot_id, reply_vector)
            # [物理层模拟结束]

            tag_bits += frame_size * num_prices_in_batch

            # 读写器分析聚合帧
            for price, bit_pos in price_to_bit_pos_map.items():
                logical_bit_vector = [((slot_data >> bit_pos) & 1) for slot_data in physical_frame.slots]
                num_zeros = frame_size - sum(logical_bit_vector)
                
                if num_zeros == frame_size:
                    estimated_counts[price] = 0
                elif num_zeros == 0:
                    estimated_counts[price] = float('inf')  # 表示计数过高，无法估算
                else:
                    # 使用标准的零时隙估算公式
                    estimated_count = -frame_size * math.log(num_zeros / frame_size)
                    estimated_counts[price] = estimated_count

        return estimated_counts, frames_used, reader_bits, tag_bits

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        total_frames = 0
        total_bits_sent_by_reader = 0
        total_tag_bits_sent = 0

        # --- 协议超参数 ---
        # 阶段1: 粗估筛选
        COARSE_FRAME_SIZE = 128
        COARSE_BATCH_SIZE = 128
        CANDIDATE_POOL_SIZE = 20 # 筛选出前20个候选者

        # 阶段2: 精估排序
        FINE_FRAME_SIZE = 1024
        FINE_BATCH_SIZE = 32
        FINAL_CANDIDATE_SIZE = 5 # 最终选出5个进行精确计数

        # 阶段3: 精确计数
        ACCURATE_COUNT_FRAME_SIZE = 2048 # 用于单价计数的帧长，确保高精度

        # --- 交叉部分：融合父代A的“并行批量估算”思想与推断的父代B的“逐级过滤”思想 ---
        
        # --- 阶段 1: 粗估筛选 ---
        all_prices = list(range(price_min, price_max + 1))
        
        coarse_counts, frames, reader_bits, tag_bits = self._run_estimation_phase(
            tags, all_prices, COARSE_FRAME_SIZE, COARSE_BATCH_SIZE
        )
        total_frames += frames
        total_bits_sent_by_reader += reader_bits
        total_tag_bits_sent += tag_bits

        sorted_coarse_counts = sorted(
            coarse_counts.items(), 
            key=lambda item: (item[1] == float('inf'), item[1]), 
            reverse=True
        )
        candidate_prices = [price for price, count in sorted_coarse_counts[:CANDIDATE_POOL_SIZE]]

        if not candidate_prices:
            return [], 0, 0.0, {}

        # --- 阶段 2: 精估排序 ---
        fine_counts, frames, reader_bits, tag_bits = self._run_estimation_phase(
            tags, candidate_prices, FINE_FRAME_SIZE, FINE_BATCH_SIZE
        )
        total_frames += frames
        total_bits_sent_by_reader += reader_bits
        total_tag_bits_sent += tag_bits
        
        sorted_fine_counts = sorted(
            fine_counts.items(), 
            key=lambda item: (item[1] == float('inf'), item[1]), 
            reverse=True
        )
        final_candidate_prices = [price for price, count in sorted_fine_counts[:FINAL_CANDIDATE_SIZE]]
        
        if not final_candidate_prices:
            final_candidate_prices = [price for price, count in sorted_coarse_counts[:1] if count > 0]
            if not final_candidate_prices:
                 return [], 0, 0.0, {"stage": "coarse", "message": "No tags found"}
        
        # --- 突变部分：引入“单价精确计数”全新机制，从概率估算转向确定性计数 ---

        # --- 阶段 3: 精确计数 ---
        final_counts = {}
        for price in final_candidate_prices:
            seed = generate_random_seed()
            total_frames += 1
            total_bits_sent_by_reader += (seed.bit_length() + ACCURATE_COUNT_FRAME_SIZE.bit_length() + price.bit_length())

            # [物理层模拟]
            physical_frame = Frame(num_slots=ACCURATE_COUNT_FRAME_SIZE, bits_per_slot=1)
            for t in tags:
                if t.price == price:
                    slot_id = simple_hash(t.id, seed) % ACCURATE_COUNT_FRAME_SIZE
                    physical_frame.aggregate(slot_id, 1)
            # [物理层模拟结束]
            
            total_tag_bits_sent += ACCURATE_COUNT_FRAME_SIZE * 1

            # --- 读写器分析 (ERROR HANDLED) ---
            num_zeros = physical_frame.slots.count(0)
            if num_zeros == ACCURATE_COUNT_FRAME_SIZE:
                final_counts[price] = 0
            elif num_zeros == 0:
                # 如果帧饱和，无法精确估算，标记为无穷大
                final_counts[price] = float('inf')
            else:
                # 只有在 num_zeros > 0 时才进行log计算
                estimated_count = -ACCURATE_COUNT_FRAME_SIZE * math.log(num_zeros / ACCURATE_COUNT_FRAME_SIZE)
                final_counts[price] = estimated_count

        # --- 结果汇总与时间计算 ---
        if not final_counts:
            return [], 0, 0.0, {"stage": "final", "message": "Final count failed"}

        # --- (MODIFIED) 结果处理，正确处理无穷大值 ---
        inf_modes = [p for p, c in final_counts.items() if c == float('inf')]
        if inf_modes:
            # 如果有无穷大结果，它们就是众数
            max_count = float('inf')
            modes = sorted(inf_modes)
        else:
            # 否则，在有限结果中寻找最大值
            max_count = max(final_counts.values()) if final_counts else 0
            modes = sorted([p for p, c in final_counts.items() if math.isclose(c, max_count)])
        
        T_reader = total_bits_sent_by_reader * 0.025
        T_tag = total_tag_bits_sent * 0.4
        T_overhead = (total_frames - 1) * 30 if total_frames > 1 else 0
        total_time_ms = T_reader + T_tag + T_overhead

        verification_data = {
            "frame_size": ACCURATE_COUNT_FRAME_SIZE,
            "bits_per_slot": max(COARSE_BATCH_SIZE, FINE_BATCH_SIZE, 1),
            "max_frame_size": max(COARSE_FRAME_SIZE, FINE_FRAME_SIZE, ACCURATE_COUNT_FRAME_SIZE),
            "max_bits_per_slot": max(COARSE_BATCH_SIZE, FINE_BATCH_SIZE, 1),
            "stage_frame_sizes": {
                "coarse": COARSE_FRAME_SIZE,
                "fine": FINE_FRAME_SIZE,
                "accurate": ACCURATE_COUNT_FRAME_SIZE,
            },
            "stage_bits_per_slot": {
                "coarse": COARSE_BATCH_SIZE,
                "fine": FINE_BATCH_SIZE,
                "accurate": 1,
            },
            "coarse_counts": sorted_coarse_counts[:CANDIDATE_POOL_SIZE],
            "fine_counts": sorted_fine_counts[:FINAL_CANDIDATE_SIZE],
            "final_accurate_counts": final_counts,
            "total_frames": total_frames,
        }

        # 根据max_count是否为inf决定返回的计数值
        display_count = float('inf') if max_count == float('inf') else math.ceil(max_count)

        return modes, display_count, total_time_ms, verification_data

import math
from typing import List, Tuple, Dict, Set
from base import Tag, IProtocol, generate_random_seed,simple_hash


class g8_3(IProtocol):
    """
    子代协议: 混合优先级模式查询协议 (Hybrid Priority Mode-Query Protocol)

    本协议是一个为解决多众数问题而设计的全新子代协议。它严格遵循信息隔离原则，
    其核心设计体现了对两个父代协议思想的深度融合（交叉）与创新优化（突变）。

    交叉策略:
    本协议融合了父代A的“自适应帧长调整”和“分批验证”思想，以及父代B的“碰撞感知”理念。
    在过滤阶段，协议会像父代B一样收集候选价格的碰撞信息，同时像父代A一样根据信道密度动态调整帧长，
    以在不同数据分布下维持较高的过滤效率。在验证阶段，它采纳了父代A的分批处理思想，以控制通信开销。

    突变策略:
    本协议引入了一项在两个父代中都未出现过的全新机制：“基于碰撞分数的动态优先级排序与启发式提前终止”。
    不同于父代B将碰撞信息用于硬性预筛选，本协议将其作为“优先级”的指示器。在验证阶段前，
    所有候选者将根据其在过滤阶段累积的碰撞分数进行降序排列。随后，协议会优先验证最可能成为众数的候选者。
    更重要的是，在每一批验证完成后，协议会进行一次启发式检查：如果当前发现的最高频次远超次高频次，
    协议将提前终止，从而在众数分布明显的情况下大幅节省总执行时间。
    """

    def execute(self, tags: List[Tag], price_min: int, price_max: int) -> Tuple[List[int], int, float, Dict]:
        total_frames = 0
        total_bits_sent_by_reader = 0
        total_tag_response_bits = 0

        # --- 协议超参数 ---
        # 阶段一: 过滤相关
        initial_filter_frame_size = 256
        num_hash_functions = 2
        candidate_threshold = 50        # 当候选者数量小于此值时，停止过滤
        max_filter_rounds = 5           # 最大过滤轮次
        high_density_threshold = 0.8    # 帧密度过高阈值 (用于扩大帧)
        low_density_threshold = 0.3     # 帧密度过低阈值 (用于缩小帧)
        min_frame_size = 64             # 过滤帧的最小尺寸

        # 阶段二: 验证相关
        verification_frame_size = 128
        batch_size_threshold = 32       # 验证阶段中，单个批次处理的最大候选者数量

        # --- 突变部分引入的超参数 ---
        early_exit_gap_factor = 2.0     # 提前终止的频次差距因子
        min_significance_score = 15     # 触发提前终止的最低频次要求

        # ==================================================================
        #  阶段一: 自适应过滤与碰撞信息收集
        # --- 交叉部分：融合父代A的自适应帧长调整思想与父代B的碰撞感知理念 ---
        # ==================================================================
        candidate_prices: Set[int] = set(range(price_min, price_max + 1))
        # 借鉴父代B，为每个潜在价格维护一个“碰撞分数”
        collision_scores: Dict[int, int] = {p: 0 for p in candidate_prices}

        filter_rounds_done = 0
        current_filter_frame_size = initial_filter_frame_size

        while len(candidate_prices) > candidate_threshold and filter_rounds_done < max_filter_rounds:
            total_frames += num_hash_functions
            filter_seeds = [generate_random_seed() for _ in range(num_hash_functions)]
            # 读写器广播帧长和哈希种子
            total_bits_sent_by_reader += num_hash_functions * (current_filter_frame_size.bit_length() + 32) # 假设种子是32位

            # --- [物理层模拟] ---
            # 读写器准备接收帧，每个slot记录响应次数
            filter_frames_states = [[0] * current_filter_frame_size for _ in range(num_hash_functions)]
            for t in tags:
                if t.price in candidate_prices:
                    for i in range(num_hash_functions):
                        slot_id = simple_hash(t.price, filter_seeds[i]) % current_filter_frame_size
                        filter_frames_states[i][slot_id] += 1
            # 在过滤阶段，标签只回复1比特表示存在性
            total_tag_response_bits += current_filter_frame_size * num_hash_functions * 1
            # --- [物理层模拟结束] ---

            # 读写器分析聚合信号
            new_candidates = set()
            for p in candidate_prices:
                is_still_candidate = True
                for i in range(num_hash_functions):
                    slot_id = simple_hash(p, filter_seeds[i]) % current_filter_frame_size
                    slot_count = filter_frames_states[i][slot_id]

                    if slot_count == 0:
                        is_still_candidate = False
                        break
                    # 如果价格p映射到了一个碰撞时隙，增加其碰撞分数
                    if slot_count > 1:
                        collision_scores[p] += 1
                
                if is_still_candidate:
                    new_candidates.add(p)

            if not new_candidates:
                break
            candidate_prices = new_candidates
            filter_rounds_done += 1

            # 借鉴父代A，根据帧密度自适应调整帧长
            total_slots_in_round = num_hash_functions * current_filter_frame_size
            total_non_empty_slots = sum(sum(1 for count in frame if count > 0) for frame in filter_frames_states)
            density = total_non_empty_slots / total_slots_in_round if total_slots_in_round > 0 else 0

            if density > high_density_threshold:
                current_filter_frame_size *= 2
            elif density < low_density_threshold:
                new_size = current_filter_frame_size // 2
                current_filter_frame_size = max(min_frame_size, new_size)

        # ==================================================================
        #  阶段二: 优先级批处理验证与提前终止
        # --- 突变部分：引入基于碰撞分数的候选者动态排序与验证阶段的启发式提前终止机制 ---
        # --- 交叉部分：验证的核心逻辑继承自父代A的并行位图与分批处理思想 ---
        # ==================================================================
        final_scores: Dict[int, int] = {}
        
        if candidate_prices:
            # 突变核心：根据碰撞分数对候选者进行降序排列，高分者优先验证
            prioritized_candidate_list = sorted(list(candidate_prices), key=lambda p: collision_scores.get(p, 0), reverse=True)
            
            num_candidates = len(prioritized_candidate_list)
            num_batches = math.ceil(num_candidates / batch_size_threshold)
            
            for i in range(num_batches):
                batch_candidates = prioritized_candidate_list[i * batch_size_threshold : (i + 1) * batch_size_threshold]
                if not batch_candidates: continue

                total_frames += 1
                price_to_bit_pos_map = {price: j for j, price in enumerate(batch_candidates)}
                bits_per_slot = len(batch_candidates)

                seed_verify = generate_random_seed()
                # 读写器广播验证参数
                total_bits_sent_by_reader += (verification_frame_size.bit_length() +
                                              seed_verify.bit_length() +
                                              sum(p.bit_length() for p in batch_candidates))

                # --- [物理层模拟] ---
                verification_frame_slots = [0] * verification_frame_size
                for t in tags:
                    if t.price in price_to_bit_pos_map:
                        slot_id = simple_hash(t.id, seed_verify) % verification_frame_size
                        bit_pos = price_to_bit_pos_map[t.price]
                        verification_frame_slots[slot_id] |= (1 << bit_pos)
                
                total_tag_response_bits += verification_frame_size * bits_per_slot
                # --- [物理层模拟结束] ---
                
                # 读写器分析聚合信号，计算当前批次中每个价格的得分
                for price, bit_pos in price_to_bit_pos_map.items():
                    score = sum(((slot_data >> bit_pos) & 1) for slot_data in verification_frame_slots)
                    if score > 0:
                        final_scores[price] = final_scores.get(price, 0) + score
                
                # 突变核心：启发式提前终止检查
                if final_scores:
                    sorted_scores = sorted(final_scores.values(), reverse=True)
                    global_max_score = sorted_scores[0]
                    # 只有当存在至少两个不同分数时才进行比较
                    if len(sorted_scores) > 1:
                        global_second_max_score = sorted_scores[1]
                        if global_max_score >= min_significance_score and \
                           global_max_score >= global_second_max_score * early_exit_gap_factor:
                            # 提前终止条件满足，跳出验证循环
                            break 
        
        # ==================================================================
        #  最终处理与时间计算
        # ==================================================================
        T_reader = total_bits_sent_by_reader * 0.025
        T_tag = total_tag_response_bits * 0.4
        T_overhead = (total_frames - 1) * 30 if total_frames > 0 else 0
        total_time_ms = T_reader + T_tag + T_overhead

        debug_data = {
            "filter_rounds_done": filter_rounds_done,
            "num_candidates_after_filter": len(candidate_prices),
            "final_scores": final_scores
        }

        if not final_scores:
            return [], 0, total_time_ms, debug_data

        max_score = max(final_scores.values())
        modes = sorted([p for p, s in final_scores.items() if s == max_score])

        return modes, max_score, total_time_ms, debug_data
