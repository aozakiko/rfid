README for PE-IDE (协议进化与测试集成开发环境)
本文档旨在介绍 PE-IDE 工具的功能、环境要求及使用方法。
1. 环境要求 (Environment Requirements)
运行本程序需要以下环境和库：
* Python 版本: 建议使用 Python 3.8 或更高版本。
* 必需的第三方库:
   * ttkthemes: 用于提供更美观的 GUI 主题。
      * 安装命令: pip install ttkthemes
* 标准库: 程序还依赖以下 Python 标准库，通常无需额外安装：
   * tkinter (及其子模块 ttk, messagebox, scrolledtext, filedialog, Toplevel)
   * os
   * shutil
   * sys
   * pathlib
   * importlib
   * itertools
   * threading
   * queue
   * traceback
   * json
   * hashlib
2. 程序介绍 (Program Introduction)
PE-IDE 是一个专为协议进化研究设计的集成开发环境。它提供了一个图形化界面，用于管理进化场景、编辑与测试协议代码、配置模拟参数以及生成用于驱动 LLM 进化的提示词。
2.1 登录/注册界面 (Login/Register Window)
* 功能: 程序启动时首先显示此窗口，用于用户身份验证。
* 认证方式: 采用本地用户名/密码认证。
* 存储: 用户名和经过 SHA-256 哈希处理的密码存储在程序根目录下的 users.json 文件中。
* 操作: 用户可以选择“登录”现有账号或“注册”新账号。注册成功后需重新登录。关闭此窗口将退出程序（如果未登录）。
2.2 主界面布局 (Main Window Layout)
成功登录后显示主界面，主要分为三个区域：
* 顶部用户状态栏 (Top User Status Bar):
   * 显示当前登录的用户名。
   * 提供“登出”按钮，点击后将返回登录界面。
* 左侧控制面板 (Left Control Panel):
   * 创建新场景: 输入场景名称，点击“创建”按钮，用于初始化一个新的进化实验环境。
   * 选择场景: 列表框显示所有已创建的有效场景（包含 generation_0 文件夹的目录）。点击选择一个场景以在右侧进行操作。
   * 刷新场景列表: 重新扫描程序根目录，更新场景列表。
* 右侧选项卡界面 (Right Notebook Interface): 包含核心功能模块，通过选项卡切换。
2.3 选项卡功能 (Tab Functions)
* 协议工作区 (Protocol Workspace):
   * 场景内容 (Scene Content): 以树状视图展示当前选定场景下的所有世代 (generation_X) 及其包含的协议 (.py 文件)。
      * 提供“刷新”按钮更新视图。
      * 提供“删除”按钮，可删除树状视图中选中的协议文件（会弹出确认框）。
   * 代码编辑器 (Code Editor):
      * 显示在树状视图中选中的协议文件的完整代码。
      * 允许用户编辑代码或粘贴由 LLM 生成的新代码。
      * 提供“文件名”输入框。
      * 提供“目标世代”下拉框，可以选择将当前编辑器中的代码保存到哪个世代文件夹（包括创建新世代）。
      * 提供“保存/更新”按钮，将代码保存到指定文件和世代。如果文件已存在，会提示是否覆盖。
   * 测试输出 (Test Output):
      * 显示协议验证和性能测试的日志信息及最终报告。
      * 提供“测试选中协议”按钮，用于对当前在树状视图中选中的协议执行测试流程。
      * 提供“清空控制台”按钮。
* 场景配置 (config.py) (Scene Configuration):
   * 功能: 用于编辑当前选定场景的模拟参数。这些参数存储在场景根目录下的 config.py 文件中。
   * 可配置参数:
      * NUM_TAGS: 模拟的标签数量
      * PRICE_MIN: 价格的最小值
      * PRICE_MAX: 价格的最大值
      * TOTAL_RUNS: 每个协议的重复测试次数
   * 操作: 在对应的输入框中修改数值（必须为整数），然后点击“保存配置”按钮将更改写入 config.py。
* 任务编辑器 (Task.py) (Task Editor):
   * 功能: 用于编辑当前选定场景的标签生成逻辑。代码存储在场景根目录下的 Task.py 文件中。
   * 核心函数: generate_tags(num_tags, price_min, price_max)，需要返回一个 Tag 对象列表和包含真实众数信息的字典。
   * 操作: 在代码框中编辑 Python 代码，然后点击“保存 Task.py”按钮。
* 提示词生成 (Prompt Generation):
   * 功能: 根据用户指定的父代协议，调用 prompt_generation.py 模块生成用于 LLM 进化的交叉提示词。
   * 操作:
      1. 在左侧面板选择目标场景。
      2. 在此选项卡的 5 个输入框中，填入父代协议的文件名（不带 .py 后缀，例如 protocol_v1 或 g0_protocolA）。至少需要输入两个。
      3. 点击“生成交叉提示词”按钮。
      4. 程序会自动查找这些协议文件（优先在当前场景的各世代中查找，然后查找 base_protocol），读取其代码，并生成所有可能的父代对组合的提示词文本文件。
      5. 生成的提示词文件将保存在当前场景的 prompts 文件夹下，文件名格式为 [父代A]_[父代B].txt。
      6. 操作完成后会弹出报告，告知成功生成了多少文件以及可能出现的错误。
3. 操作指南 (User Guide)
以下是使用 PE-IDE 进行一次完整协议进化实验的标准流程：
1. 首次运行与注册/登录:
   * 确保已安装 ttkthemes 库 (pip install ttkthemes)。
   * 运行 protocol_evolution_gui.py。
   * 在弹出的登录窗口中，如果是首次使用，输入 желаемый 用户名和密码，点击“注册”。注册成功后，使用刚注册的账号点击“登录”。
   * 程序首次运行时，会自动在根目录创建 base_protocol 文件夹（包含 5 个基础协议模板）和 users.json 文件（如果不存在）。
2. 创建新场景:
   * 在左侧“新场景名”输入框中输入一个描述性的名称（例如 multi_mode_evolution_test），避免使用非法字符。
   * 点击“创建”按钮。程序将创建对应的文件夹，并自动生成 generation_0（包含基础协议）、prompts 文件夹、config.py 和 Task.py 文件。
3. 配置场景参数与任务 (可选):
   * 配置参数: 切换到“场景配置 (config.py)”选项卡，根据实验需求修改 NUM_TAGS, PRICE_MIN, PRICE_MAX, TOTAL_RUNS 的值，然后点击“保存配置”。
   * 定义任务: 切换到“任务编辑器 (Task.py)”选项卡，修改 generate_tags 函数以定义特定的标签分布和众数场景，然后点击“保存 Task.py”。
4. 生成第一代提示词:
   * 确保左侧已选中您创建的场景。
   * 切换到“提示词生成”选项卡。
   * 由于是第一代进化，父代通常来自 generation_0 或 base_protocol。在输入框中填入 5 个父代协议的名称（例如 protocol_v1, protocol_v2, ..., protocol_v5）。
   * 点击“生成交叉提示词”。生成的 .txt 文件会出现在场景的 prompts 文件夹内。
5. 使用 LLM 生成子代协议:
   * 打开 [场景名]/prompts 文件夹，选择一个生成的提示词文件（例如 protocol_v1_protocol_v2.txt）。
   * 复制文件中的全部内容。
   * 将复制的提示词粘贴到您选择的大语言模型（如 ChatGPT, Claude, Gemini 等）的输入中，让其生成新的协议代码。
   * 仔细检查 LLM 生成的代码是否符合 base.py 中定义的 IProtocol 接口要求，并确保其逻辑基本合理。
   * 复制 LLM 生成的完整 Python 类代码。
6. 保存子代协议到新世代:
   * 返回 PE-IDE，切换到“协议工作区”选项卡。
   * 将从 LLM 复制的代码粘贴到中央的代码编辑器中。
   * 在“文件名”输入框中为新协议命名（例如 g1_proto_A.py，建议包含代数信息）。
   * 在“目标世代”下拉框中，选择 [ 创建新世代 ]（通常会是 generation_1）。
   * 点击“保存/更新”按钮。新协议将保存到 [场景名]/generation_1/ 目录下。
   * 重复步骤 5 和 6，为 generation_1 生成足够数量（例如 N=5 个）的子代协议。
7. 测试新协议:
   * 在“协议工作区”的树状视图中，展开 generation_1，点击选择您刚保存的一个协议（例如 g1_proto_A.py）。代码会显示在编辑器中。
   * 点击编辑器下方的“测试选中协议”按钮。
   * 观察下方“测试输出”控制台。程序会依次执行加载配置、加载任务、加载协议、约束验证和性能测试。最终会输出测试报告，包含通过率和平均执行时间。
   * 对 generation_1 中的其他协议重复此测试步骤。
8. 迭代进化:
   * 基于 generation_1 中协议的测试结果（适应度），选择表现较好的协议作为下一轮进化的父代。
   * 切换到“提示词生成”选项卡，在输入框中填入选定的 generation_1 协议名称（例如 g1_proto_A, g1_proto_C, ...）。
   * 点击“生成交叉提示词”，生成用于产生 generation_2 的提示词，保存在 prompts 文件夹。
   * 重复步骤 5（使用新提示词与 LLM 交互）、步骤 6（保存到 generation_2）和步骤 7（测试 generation_2 的协议）。
   * 持续这个循环（选择父代 -> 生成提示词 -> LLM 生成子代 -> 保存 -> 测试），直到达到预设的最大进化代数 G，或者找到满足性能要求的协议。
9. 管理与维护:
   * 使用树状视图旁的“刷新”按钮可以更新场景内容显示。
   * 对于不再需要或表现差的协议，可以在树状视图中选中它，然后点击“删除”按钮进行清理。
通过以上步骤，您可以利用 PE-IDE 工具系统地进行基于 LLM 的协议进化实验。
